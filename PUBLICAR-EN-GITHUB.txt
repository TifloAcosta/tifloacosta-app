TifloAcosta App v0.3 — paquete preparado para GitHub Pages

1. No subas el ZIP. Descomprímelo.
2. En el repositorio de GitHub sube el CONTENIDO de esta carpeta a la raíz del repositorio.
3. Deben quedar index.html, app.js, data.js, styles.css, sw.js, manifest.webmanifest, offline.html, .nojekyll y la carpeta icons en el nivel principal.
4. En Settings > Pages, selecciona Deploy from a branch, rama main y carpeta /(root), y guarda.
5. Cuando GitHub indique que el sitio está publicado, abre Visit site.
