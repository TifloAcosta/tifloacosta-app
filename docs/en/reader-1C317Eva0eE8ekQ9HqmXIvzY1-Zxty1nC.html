Complete Course on Braille Screen Input on iPhone

From zero to advanced and professional use

Primary reference: iOS 27, with useful notes for iOS 26

Created by Tony Acosta for TifloAcosta

Introduction

This course starts from scratch. We are going to type braille directly on the iPhone screen with VoiceOver, without assuming that you already know Braille Screen Input or feel confident with its gestures. If you already know braille, you will move faster; if not, we will build the basics while we practise.

We will work with iPhone and VoiceOver, using iOS 27 as the main reference. When iOS 26 behaves differently in a way that changes what you actually have to do, I will point it out where it matters. If the procedure is the same in both versions, I am not going to repeat it just to make the course longer.

For the English edition, the braille examples follow Unified English Braille, or UEB. We will use uncontracted six-dot braille for the foundations, then explain where contracted braille fits once the basic movements are already familiar.

We will go step by step. First we place the fingers and type individual characters. Then come spaces, deletion, numbers, punctuation and real apps. Later we will move around inside text, enter Command Mode, build speed, deal with the usual problems and try more advanced options such as one-handed input.

Do not try to memorise everything in one sitting. The appendices are there for a reason: when you need a gesture, a dot combination or a reminder about versions, you can look it up without walking through the whole course again.

Module 1. Starting from zero

Braille Screen Input lets you type on the iPhone by using your fingers as if you had the six keys of a braille machine in front of you. There is no physical keyboard to find and no row of onscreen keys to hunt for. You place your fingers on areas of the screen and form each character by pressing the dots it needs at the same time. Simple idea; slightly strange feeling the first few times.

At first you may think, “dot 1, dot 2, dot 4…” as if you were doing a calculation. With practice, that calculation disappears and the hands begin to recognise letters on their own. Moving from thinking about dots to simply writing is exactly what we are going to train.

One distinction is worth making right away because the names can easily get mixed up. A refreshable braille display is a separate physical device connected to the iPhone, with real braille cells you can read by touch. Braille Screen Input uses only the iPhone touchscreen. Both involve braille, but they are very different ways of working.

This is not meant to replace a complete braille literacy course either. If you already know braille, you have a head start. If you only know a little, you can still follow the typing exercises because we will introduce the combinations as we need them. The aim here is practical: to make braille a comfortable way to write on the iPhone, not to turn the course into a theory exam.

And practical means more than putting letters one after another. We want to write messages, notes, emails and longer pieces of text; handle numbers and punctuation; notice that we made a mistake several words ago; move back, fix it and carry on without losing the thread.

Forget speed during the first practices. One correctly typed letter is worth more than ten rushed ones that need fixing afterwards. Accuracy and comfort come first. Speed usually turns up later, once the movements stop feeling new.

We will begin with uncontracted six-dot UEB. Contracted braille, other input modes and more advanced options will appear when they are useful. Throwing every feature onto the table on day one would only give us a larger table to tidy up.

The size of the iPhone and the size of your hands both affect comfort. A position that feels perfect to one person may be awkward for another. We will try the main positions and you can keep the one that works best for you.

Braille Screen Input also lives happily alongside dictation, the standard onscreen keyboard, a physical keyboard and a refreshable braille display. Learning it gives you another way to write; it does not take any of the others away.

With that sorted, we can prepare the phone.

Module 2. Preparing the iPhone

Before typing the first letter, it is worth spending a few minutes on setup. The fewer things we change at the beginning, the easier it is to understand what is happening once we start practising.

Braille Screen Input is part of VoiceOver. Its main settings are under:

Settings > Accessibility > VoiceOver > Braille > Braille Screen Input

To get started, we need two things: a reliable way to enter Braille Screen Input when we are in an editable field, and an English braille table that matches the code we are going to use. The examples in this course follow Unified English Braille, or UEB.

Activation with the rotor

The rotor is the safest route in. When you are in a text input area, set the VoiceOver rotor to Braille Screen Input and you are ready to type.

If Braille Screen Input is not available in the rotor, check:

Settings > Accessibility > VoiceOver > Rotor > Rotor Items > Braille Screen Input

Direct activation

Current versions also offer a direct activation gesture. If Use Activation Gestures is turned on, place one finger from each hand at the top and bottom edges of the screen and double-tap.

Use whichever route feels more natural. And keep the rotor in mind as the dependable way back in if the direct gesture ever decides not to cooperate.

Braille table and initial settings

The braille table does matter from the beginning. For this English edition, use an English UEB table appropriate to your setup. Apple can offer different tables and contracted or uncontracted options, so check the active table before blaming your fingers if punctuation suddenly starts behaving strangely.

Inside Braille Screen Input settings you will also find options such as starting automatically when editing text, keeping Braille Screen Input active until you dismiss it, learning dot positions, reversing dot positions, choosing feedback while you type, configuring one-handed input and choosing a braille table.

A simple setup is enough for the first practices. Add the extra options later, when you know what problem you actually want them to solve.

Module 3. First contact with Braille Screen Input

Open a new note. It is a good place to experiment without pressure: if you type nonsense, nobody receives it; if you delete half a sentence by accident, nobody complains.

Create a new note, move to the text area and start Braille Screen Input.

The two main positions

The iPhone can be flat on a surface in Tabletop Mode, or held horizontally with the screen facing away from you in Screen Away Mode. Tabletop Mode is often easier for understanding where each finger sits. Screen Away Mode is commonly used when you are holding the phone in your hands.

With six-dot braille, the usual reference is:

  • Left hand: index finger, dot 1; middle finger, dot 2; ring finger, dot 3.
  • Right hand: index finger, dot 4; middle finger, dot 5; ring finger, dot 6.

Rest the six fingers naturally. Your hands should not feel rigid or stretched. If the position is uncomfortable, move the phone before you move on. There is no prize for making your wrists miserable.

Calibrating the dot positions

If the screen stops matching the natural position of your fingers, you can recalibrate. On iPhone, tap and release the three dot positions on the right hand together to set dots 4, 5 and 6, then immediately tap and release the three positions on the left hand together to set dots 1, 2 and 3.

One stray typo is not a reason to recalibrate; we all make those. Recalibrate when several attempts suggest that the dot positions have genuinely shifted. You can also turn on Learn Dot Positions so Braille Screen Input adjusts to your fingers as you use it.

First taps

Before forming words, tap one dot, then two together, and listen to what VoiceOver reports. For these first minutes, the job is simply to get used to pressing several fingers at once without sliding the whole hand across the screen.

Then try Screen Away Mode. The physical feeling changes quite a lot, but the dot numbers do not. You may prefer one position immediately, or you may need a few sessions before you know. Either is fine.

Leaving Braille Screen Input

To exit, slide two fingers in opposite directions. You can also use the two-finger scrub, the familiar VoiceOver “z” gesture for going back.

Module 4. Learning to type without rushing

A six-dot braille cell is built from dots 1 through 6. To type a letter, press the dots that make up that letter at the same time. We will start with the alphabet in families rather than treating twenty-six letters as twenty-six unrelated passwords.

The first ten letters

  • a: dot 1.
  • b: dots 1-2.
  • c: dots 1-4.
  • d: dots 1-4-5.
  • e: dots 1-5.
  • f: dots 1-2-4.
  • g: dots 1-2-4-5.
  • h: dots 1-2-5.
  • i: dots 2-4.
  • j: dots 2-4-5.

Start with a few and add more when your fingers can already find the first ones without a long meeting in your head.

The second group

  • k: dots 1-3.
  • l: dots 1-2-3.
  • m: dots 1-3-4.
  • n: dots 1-3-4-5.
  • o: dots 1-3-5.
  • p: dots 1-2-3-4.
  • q: dots 1-2-3-4-5.
  • r: dots 1-2-3-5.
  • s: dots 2-3-4.
  • t: dots 2-3-4-5.

Notice the pattern: much of this second group comes from the first ten letters with dot 3 added. Seeing the family is far more useful than memorising twenty separate dot recipes.

The remaining letters

  • u: dots 1-3-6.
  • v: dots 1-2-3-6.
  • w: dots 2-4-5-6.
  • x: dots 1-3-4-6.
  • y: dots 1-3-4-5-6.
  • z: dots 1-3-5-6.

The w is the odd one out in the usual pattern, for historical reasons. You do not need the history lesson to type it; just give that combination a little extra practice if it refuses to stick.

Now try a few simple words: home, name, time, message, hello. Listen as you type and, if a combination comes out wrong, fix that character and carry on instead of starting the whole word again.

Then type your own name. You know exactly what it should sound like, which makes mistakes very easy to spot.

When several letters begin to flow without a pause before each one, try short phrases:

hello my name is [your name]

i am learning braille on the iphone

It is completely normal to keep thinking about the dots for some letters at this stage. That little internal voice fades with practice. When a familiar word comes out without you reciting its dots to yourself, you have made real progress.

Module 5. Now we are actually writing

So far we have mostly dealt with letters and isolated words. To write complete sentences we need three more actions that will eventually become automatic: space, delete and new line.

Space and delete

Swipe right with one finger to enter a space. Swipe left with one finger to delete the previous character.

If you know the last character is wrong, fix it there and then and keep going. Rewriting a whole word or sentence for every small typo only slows you down.

Try:

meet me at home

today feels quiet

New line and Return

Swipe right with two fingers to move to a new line. In an ordinary text editor, that simply starts the next line. In some apps, Return can perform a different action depending on the field you are in.

Swipe up with three fingers to enter a carriage return. In Messages, depending on the context, that same gesture can send the message, so it is worth knowing what control you are in before using it casually.

Write three things you did today, one on each line. Once you have to think about the content while your fingers type, Braille Screen Input stops feeling like a string of exercises and starts behaving like the tool it actually is.

Module 6. Capitals, numbers, punctuation and braille tables

Lowercase letters are enough for early practice, but real English brings proper names, dates, times, prices, apostrophes, questions and plenty of punctuation.

Capital letters in UEB

In Unified English Braille, a single capital letter is introduced with the capital indicator, dot 6, followed by the letter itself. To write Tony, for example, enter dot 6 and then t; the remaining letters are written normally.

For a whole word in capitals, UEB uses the capital word indicator: dot 6 twice before the word. You do not need it for every exercise, but it is useful to know that the code has a proper way to distinguish one capital letter from an entire capitalised word.

Numbers

The numeric indicator is dots 3-4-5-6. After it, the combinations for the first ten letters represent the digits:

  • a = 1
  • b = 2
  • c = 3
  • d = 4
  • e = 5
  • f = 6
  • g = 7
  • h = 8
  • i = 9
  • j = 0

Start with single digits and then use something real: an age, a time, a date or a small amount.

25

10

2026

meet me at 10

the appointment is on the 25th

Slow down a little with numbers. A misspelled word often gives itself away from the context; a wrong digit can look perfectly respectable while changing the information completely.

Basic UEB punctuation

  • Comma: dot 2.
  • Semicolon: dots 2-3.
  • Colon: dots 2-5.
  • Period or full stop: dots 2-5-6.
  • Question mark: dots 2-3-6.
  • Exclamation mark: dots 2-3-5.
  • Apostrophe: dot 3.
  • Hyphen: dots 3-6.

Try a few ordinary sentences rather than drilling punctuation in isolation:

Hello, how are you?

That's fine!

Meet me at 10.

Uncontracted and contracted UEB

English braille has one extra decision that matters more than it does in many other languages: uncontracted or contracted braille. Uncontracted UEB writes words letter by letter. Contracted UEB uses established contractions and groupsigns to reduce the number of cells.

This course teaches the foundations in uncontracted braille so that every exercise is clear even if you are new to UEB. If you already know contracted UEB, Braille Screen Input can use it. The contractions are part of the braille code, not shortcuts invented by the iPhone, so use them according to UEB rules rather than guessing at abbreviations.

Braille tables

The active table determines how symbols and contractions are interpreted. If ordinary letters work but punctuation or contractions suddenly behave strangely, check the braille table before changing anything else.

Swipe up with two fingers to switch to the next braille table. When you are typing contracted braille, swipe down with two fingers to translate immediately if you need the text converted at that point.

Module 7. Writing in real apps

Braille Screen Input belongs to VoiceOver, so you can use it in most places where the iPhone gives you an editable text field: Messages, WhatsApp, Mail, Safari, forms and many other apps.

The braille itself does not change. The context does.

Messages and WhatsApp

Open a conversation where you can practise without pressure, find the message field and start Braille Screen Input. Write something you might genuinely send:

I will be there in ten minutes.

Before sending, let VoiceOver read the text back and check that it says what you intended. At the beginning it helps to keep “write” and “send” as two separate steps.

Email

Mail gives you several important fields: recipient, subject and message body. Create a new message without sending it. Write a short subject, then two or three lines in the body.

Subject: tomorrow's meeting

Hello.

I'm writing to confirm that I'll be there at 10.

Best,

Email addresses and web addresses deserve more checking than an ordinary sentence. One small error can make the entire address useless.

Safari and forms

In Safari, practise with the search field: type, review, then run the search with the appropriate control.

In forms, identify the field first and type second. Name, address, phone number, email and password fields can sit one after another, and rushing makes them much easier to mix up.

Password fields deserve special care. For privacy, VoiceOver may give less feedback than usual. If another input method feels safer for a particular password or code, use it. The goal is to enter the right information, not to prove loyalty to one keyboard.

If one app behaves oddly, try the same kind of typing in another simple text field. That comparison quickly tells you whether the problem is Braille Screen Input in general or that particular control.

Module 8. Moving around and correcting text

When the mistake is at the end, deleting and carrying on is easy. The fun starts when you finish a paragraph, listen back and discover that the wrong word is several lines behind you.

Deleting all the way back to it destroys far too much good text. We need another strategy: movement.

The safe route with VoiceOver

We will begin with a very reliable method: leave Braille Screen Input for a moment, orient yourself with VoiceOver, and return to braille when you reach the point where you want to edit.

Using the VoiceOver rotor, you can move by units such as lines, words or characters. A practical approach is to start broad and then narrow down: find the line, then the word and, if necessary, the exact character.

Tomorrow I am going to the doctor.

After that I will stop at the supermarket.

If you meant dentist instead of doctor, locate that word, place the insertion point where it belongs and make the change without disturbing the rest of the text.

Three editing practices

Write this sentence and replace afternoon with evening:

This afternoon I am going to call Maria with the news.

Then write:

Tomorrow I have an important appointment.

Insert the word very before important.

Finally, write:

Today I am going to the market market before lunch.

Delete only one occurrence of market and leave the sentence intact.

Braille Screen Input can also do much of this without leaving the braille environment at all. That is what Command Mode is for, and we are ready to use it properly now.

Module 9. Command Mode: controlling the iPhone from braille

Up to this point we have used Braille Screen Input mainly for typing. Command Mode lets the same six-dot layout control VoiceOver, navigate and edit without constantly leaving braille.

Entering and leaving Command Mode

Swipe left or right with three fingers to cycle through the available Braille Screen Input modes. VoiceOver announces the mode according to your Mode Announcements settings.

Listen to the active mode before entering a dot combination. In Braille Entry Mode, the dots make characters. In Command Mode, those same dots perform actions.

For example, dots 1-4 make the letter c when you are writing, but in Command Mode they perform Copy. Same fingers; very different result.

Basic navigation

  • Dot 1: previous item.
  • Dot 4: next item.
  • Dots 1-2-3: first item.
  • Dots 4-5-6: last item.
  • Dots 1-2: escape the current context.
  • Dots 2-5: open Control Center.
  • Dots 4-6: open Notification Center.
  • Dots 3-6: perform a simple tap.

Try these before editing anything. Move forward with dot 4, back with dot 1, and use dots 3-6 on an item that can be activated.

Using the rotor from Command Mode

  • Dots 2-3: previous rotor setting.
  • Dots 5-6: next rotor setting.
  • Dot 3: previous item using the selected rotor setting.
  • Dot 6: next item using the selected rotor setting.

This lets you choose a unit such as Words or Characters and move with braille commands while your hands stay in position.

Selecting and editing

  • Dots 2-3-5: extend the selection to the left.
  • Dots 2-5-6: extend the selection to the right.
  • Dots 2-3-5-6: select all.
  • Dots 1-4: copy.
  • Dots 1-3-4-6: cut.
  • Dots 1-2-3-6: paste.
  • Dots 1-3-5-6: undo typing.
  • Dots 2-3-4-6: redo typing.

Three of these are particularly easy to remember if you know the braille alphabet: dots 1-4 are c for Copy, 1-3-4-6 are x for Cut, and 1-2-3-6 are v for Paste. It is one of those rare memory tricks that actually earns its keep.

Write a sentence, find a word or short fragment, select it and try Copy, Cut and Paste. Then make a change on purpose and use Undo. Redo brings the operation back if you decide you wanted it after all.

Customising commands

VoiceOver lets you review and customise these commands under:

Settings > Accessibility > VoiceOver > Commands > Braille Screen Input

For now, the commands you genuinely use are enough. Customisation makes more sense later, once you know which actions keep coming up in your own work.

Module 10. Building speed without losing accuracy

Useful speed is not about moving the fingers as fast as possible. It comes from fewer pauses, less unnecessary movement and fewer corrections afterwards.

The first real improvement happens when you stop translating every letter into dot numbers. At the beginning you think, “m: 1-3-4.” Later you simply type m. That change comes from repetition, not from forcing yourself to hurry.

Practise words you actually use: hello, thanks, tomorrow, message, email, iPhone, VoiceOver, WhatsApp. Your fingers begin to recognise familiar sequences, and each letter stops feeling like a separate operation.

Finding a rhythm

Type a familiar sentence once at whatever pace you need, then repeat it while aiming for a steady flow:

I will call you when I get home.

Do not try to sprint through each word. Regular movement is usually more useful than bursts of speed followed by sudden stops.

Movement and posture

You do not need to lift the fingers far between one cell and the next. The larger the movement, the easier it is to lose your reference position.

Compare Tabletop Mode and Screen Away Mode for a few minutes. Notice the number of errors, how stable the finger positions feel and how comfortable your hands are. One position may suit home and the other may suit being out and about. That is perfectly fine.

If the same dot repeatedly stops being recognised correctly, check your hand position and recalibrate. One isolated typo does not justify moving the reference points for all six fingers.

If you already know contracted UEB, contractions can reduce the number of cells you type and increase practical speed. They help most when the contractions themselves are automatic. If you have to stop and work out every contraction, uncontracted braille will be faster for the moment.

Measuring progress

Use a four- or five-line passage as a reference. Type it again a few days later and notice two things: how long it takes and how many errors you make.

An even better test is to write something you are not copying. Spend three minutes writing about any subject that comes to mind. If you can think about what you want to say while your fingers take care of the braille, Braille Screen Input is beginning to become a working tool.

Five or ten focused minutes can be more useful than a long session once your hands and attention are tired. There is no need to grind away at it.

Module 11. When something does not work

Troubleshooting becomes much easier when you can say exactly what is failing. “Braille does not work” can mean ten different things, and each one points in a different direction.

I cannot start Braille Screen Input

Check that VoiceOver is on, that you are in an editable text field and that Braille Screen Input is available. If the direct activation gesture does not respond, try the rotor. If the rotor works, you already know that Braille Screen Input itself is available and the problem is with the activation route.

I try to type and actions happen instead

Check the active mode. In Command Mode, dot combinations perform actions instead of entering characters. That single check can save a surprising amount of detective work.

The letters come out wrong

Try very simple characters such as a, b and c. Notice whether the same dot is involved each time. Reposition your hands and make sure the phone has not shifted. If the pattern continues, recalibration makes sense.

Letters are fine but punctuation or contractions are wrong

Check the active braille table and whether you are using contracted or uncontracted input. A table or mode change can be almost invisible while typing ordinary letters and become obvious only when punctuation or contractions appear.

Only one app is failing

Try another text field or a simple app. If Braille Screen Input works there, leave the general VoiceOver settings alone. The problem is more likely to be that app or that particular control.

I have lost my place in the text

Stop making random gestures; they usually make the situation worse. Leave Braille Screen Input if that helps, listen to the surrounding text with VoiceOver, find a phrase you recognise and recover the insertion point from there.

Restarting and final checks

If the strange behaviour affects several things at once, turning VoiceOver off and back on is a reasonable test. If it continues, restart the iPhone before changing settings that were working perfectly well five minutes earlier.

A sensible order is: editable field, active mode, braille table, finger position, test in another app, recalibrate if the dot problem repeats, restart VoiceOver, and finally restart the iPhone if the issue is system-wide.

Module 12. From advanced use to professional use

There comes a point when you stop thinking, “I am using Braille Screen Input,” and you are simply writing. Your attention moves to the task: replying to a message, taking notes, writing an email or working on a longer document.

Long texts and quick notes

In a long text, separate obvious typing mistakes from sentences you may want to improve later. Fix the typo immediately; the sentence can wait for the editing pass. Working in blocks helps you keep the thread of what you are trying to say.

Quick notes are different. In a meeting, class or conversation, capturing the idea may matter more than polishing the sentence. Keywords, personal abbreviations and incomplete phrases are perfectly useful if you can understand them later.

Braille Screen Input also has a clear advantage over dictation in some situations: you can write without speaking aloud. In a waiting room or a meeting, that can be worth quite a lot.

Exact information

Slow down deliberately for phone numbers, dates, amounts, email addresses, web addresses, passwords and anything else that has to be exact. A sentence can survive a typo. A phone number may not.

iOS text replacements can also save time on phrases you type often. Choose abbreviations that are unlikely to appear in normal conversation, unless you enjoy watching your full postal address expand in the middle of an innocent sentence.

One-handed input

Braille Screen Input includes specific styles for typing with one hand. This is not an iOS 27-only feature; it was already available in iOS 26 and remains part of the current system.

Configure it under:

Settings > Accessibility > VoiceOver > Braille > Braille Screen Input

One-handed input is used with the iPhone in portrait orientation and offers three styles.

Right Hand or Left Hand

The braille cell is built by columns: dots 1-4, then 2-5, then 3-6. Enter each column in turn. If a column should be blank, swipe right to enter an empty column. When the cell is complete, double-tap to enter it. Right Hand is the default setting.

Start with letters you know very well, then short words, space and delete, and only then move to sentences. One-handed input has its own muscle memory. Knowing two-handed braille does not make the new movement automatic on day one.

Slate and Stylus

In this style, the screen acts as a six-dot braille cell with dots 1, 2 and 3 on the right and dots 4, 5 and 6 on the left. The arrangement follows the logic of traditional slate-and-stylus writing, so people who already know that method may find it familiar.

Reverse Slate and Stylus

Here the arrangement is reversed: dots 1, 2 and 3 are on the left and dots 4, 5 and 6 are on the right.

One-handed input can be useful permanently, temporarily, because of a particular posture, or simply because it feels better to you. It is another option, not a requirement.

Braille Screen Input, a braille display and Braille Access

Braille Screen Input uses the iPhone touchscreen for typing. A refreshable braille display is a physical device connected to the iPhone. Braille Access is a separate environment designed for use with a connected braille device, with features such as braille notes, BRF files and calculations.

They share the word braille, but they are not the same tool and they are not meant to do exactly the same job.

Privacy and choosing the right tool

Braille lets you write without speaking, but VoiceOver may still read what you enter. In a public place, headphones can matter just as much as any keyboard setting.

Braille Screen Input, dictation, a physical keyboard and a refreshable braille display can all live together. Independence also means choosing the tool that fits the task in front of you.

Module 13. Final practice: putting everything together

We have practised the pieces separately: typing, spacing, deleting, numbers and punctuation, moving through text, correcting something that is no longer at the end, changing apps and recovering when things go wrong. Now we mix them, because that is how the iPhone is used in real life.

Write five or six lines about something real: what you did today, what you plan to do tomorrow, a call you need to make or any subject that does not require too much invention. Include at least one proper name, some punctuation, a number and two paragraphs.

Write the first version in one go. Fix obvious typing mistakes as they happen and leave stylistic changes until afterwards.

When you finish, go back to the beginning and make three changes: replace one word, add another somewhere in the middle and delete something near the end. The point is to return to existing text without rebuilding the whole thing every time.

Deliberately introduce a small typo near the end, type a few more words, then go back and find it. We want to know that you can repair an error that is no longer sitting next to the insertion point.

Add a sentence containing a date, a time or an amount and review it carefully, character by character.

The appointment is on the 25th at 10.

Select a sentence, copy it and paste it at the end. Then cut another short fragment and move it somewhere else. Use Undo at least once so that the safety net becomes something you have actually felt, not just something you read about.

Change apps. Draft a message you might genuinely send, then an email of several paragraphs without sending it. When you reach the second paragraph, go back and change something in the first so that moving backwards and forwards becomes part of the exercise.

Type an email address and a phone number you know. Review them character by character. With exact data, every character matters.

Finally, move through the text using different units: lines, words and characters. Return to the end afterwards. If you lose your position, find it again and continue. That recovery is part of the skill.

The best test after this module is to use Braille Screen Input for something you genuinely need to do. That is where you discover whether it has become a useful tool or is still only an exercise.

Module 14. Finishing the course without finishing the learning

I could keep adding features for many more pages. There is always another setting or another command we have not discussed. But eventually collecting more information helps less than using what you already know.

Different parts of Braille Screen Input will not become comfortable at exactly the same pace. You may type words fluently and still hesitate over numbers. Punctuation may be easy while editing several lines back still takes effort. Practise the part that makes you stop.

A small routine is usually enough: one message, a list, a few lines of text, a web search or a reply to an email. When practice looks like real life, it stops feeling like homework.

Over time, everyone develops a personal way of using Braille Screen Input. Some people want plenty of VoiceOver feedback; others prefer fewer interruptions and a review at the end. Some will rely heavily on Command Mode, while others will often step back into ordinary VoiceOver navigation. There is no single correct working style.

Future iOS versions will bring changes. You do not need to learn a new feature simply because it exists. The useful question is whether it solves something you actually do.

One skill is worth keeping above any individual gesture: the ability to return to familiar ground. If you changed modes by mistake, switch back. If you lost your position, orient yourself. If one app behaves strangely, test another field. If punctuation looks wrong, check the table.

Experience does not remove every mistake. It changes what happens after the mistake: you usually know how to fix it and keep going.

At first we think in dots. Then we begin to think in words. Eventually we can concentrate on what we actually want to write. That is the journey we were aiming for from the first module.

The two appendices that follow are for looking things up when you need them, not for memorising.

Appendix A. Quick reference

This appendix is for checking a route, gesture or dot combination quickly. The explanations and practice are in the modules.

Settings

Settings > Accessibility > VoiceOver > Braille > Braille Screen Input

From here you can configure activation gestures, automatic start when editing, keeping Braille Screen Input active until dismissed, dot positions, typing feedback, mode announcements, one-handed input and braille tables.

Starting Braille Screen Input

  • With the rotor: in a text field, set the rotor to Braille Screen Input.
  • If it is not in the rotor: Settings > Accessibility > VoiceOver > Rotor > Rotor Items > Braille Screen Input.
  • With the direct gesture, if enabled: place one finger from each hand at the top and bottom edges of the screen and double-tap.

Six-dot layout

  • Left hand: index finger, dot 1; middle finger, dot 2; ring finger, dot 3.
  • Right hand: index finger, dot 4; middle finger, dot 5; ring finger, dot 6.

Main gestures

  • Swipe right with one finger: space.
  • Swipe left with one finger: delete the previous character.
  • Swipe right with two fingers: new line.
  • Swipe up or down with one finger: cycle through spelling suggestions.
  • Swipe up with three fingers: carriage return; in Messages, depending on context, it can also send.
  • Swipe left or right with three fingers: cycle through Braille Screen Input modes, including Braille Entry Mode and Command Mode.
  • Swipe up with two fingers: next braille table.
  • Swipe down with two fingers: translate immediately when typing contracted braille.

Leaving Braille Screen Input

  • Slide two fingers in opposite directions.
  • Or use the two-finger scrub, the standard VoiceOver “z” gesture for going back.

Calibration

On iPhone, tap and release the three dot positions on the right hand together to set dots 4, 5 and 6, then immediately do the same with the left hand to set dots 1, 2 and 3.

Do not recalibrate for one isolated typo. Recalibrate when the dot-position problem repeats consistently.

Command Mode

To enter or leave it, swipe left or right with three fingers until VoiceOver announces the mode you want.

  • Dot 1: previous item.
  • Dot 4: next item.
  • Dots 1-2-3: first item.
  • Dots 4-5-6: last item.
  • Dots 1-2: escape current context.
  • Dots 2-5: Control Center.
  • Dots 4-6: Notification Center.
  • Dots 3-6: simple tap.
  • Dots 2-3: previous rotor setting.
  • Dots 5-6: next rotor setting.
  • Dot 3: previous item using the rotor setting.
  • Dot 6: next item using the rotor setting.
  • Dots 2-3-5-6: select all.
  • Dots 2-3-5: extend selection left.
  • Dots 2-5-6: extend selection right.
  • Dots 1-3-4-6: cut.
  • Dots 1-4: copy.
  • Dots 1-2-3-6: paste.
  • Dots 1-3-5-6: undo typing.
  • Dots 2-3-4-6: redo typing.

UEB capitals, numbers and punctuation

  • Capital letter indicator: dot 6 before the letter.
  • Capital word indicator: dot 6 twice before a fully capitalised word.
  • Numeric indicator: dots 3-4-5-6.
  • Comma: dot 2.
  • Semicolon: dots 2-3.
  • Colon: dots 2-5.
  • Period or full stop: dots 2-5-6.
  • Question mark: dots 2-3-6.
  • Exclamation mark: dots 2-3-5.
  • Apostrophe: dot 3.
  • Hyphen: dots 3-6.

Digits after the numeric indicator

  • a = 1
  • b = 2
  • c = 3
  • d = 4
  • e = 5
  • f = 6
  • g = 7
  • h = 8
  • i = 9
  • j = 0

English braille table

The examples in this course follow Unified English Braille. Use uncontracted UEB while learning the foundations unless you already know contracted UEB well. Contracted braille follows UEB contraction rules; it is not free-form abbreviation.

One-handed input

  • Right Hand or Left Hand: columns 1-4, 2-5 and 3-6; swipe right for an empty column and double-tap to enter the completed cell.
  • Slate and Stylus: dots 1-2-3 on the right; dots 4-5-6 on the left.
  • Reverse Slate and Stylus: dots 1-2-3 on the left; dots 4-5-6 on the right.

Quick troubleshooting

  • Check that you are in an editable field.
  • Check the active Braille Screen Input mode.
  • Check the braille table and contracted/uncontracted setting.
  • Reposition the fingers and try simple characters.
  • Test another app or text field.
  • Recalibrate if the same dot-position error keeps repeating.
  • Restart VoiceOver if necessary.
  • If the problem is system-wide and continues, restart the iPhone.

Three different things

  • Braille Screen Input: uses the iPhone touchscreen directly for braille input.
  • Refreshable braille display: a physical braille device connected to the iPhone.
  • Braille Access: a dedicated environment for working with a connected braille device.

Appendix B. iOS 26 and iOS 27: what really changes

This appendix exists to avoid a very common misunderstanding: updating the iPhone and assuming that Braille Screen Input has to be learned again from the beginning.

Between iOS 26 and iOS 27, the core of Braille Screen Input remains the same. Someone who already used it in iOS 26 will find the same overall approach in iOS 27: braille entry on the touchscreen, Tabletop and Screen Away modes, braille tables, calibration, editing gestures, Command Mode and one-handed input.

What was already available in iOS 26

  • Braille Screen Input within VoiceOver.
  • Access through the rotor.
  • Direct activation gestures.
  • Tabletop and Screen Away modes.
  • Six-dot, contracted and other braille input options supported by the selected table and configuration.
  • Braille table selection and switching.
  • Dot-position calibration.
  • Learning dot positions automatically.
  • Space, delete, new line and table-switching gestures.
  • Spelling suggestions.
  • Command Mode.
  • Navigation and editing commands.
  • One-handed input styles.

So none of these should be presented as a feature that suddenly arrived with iOS 27.

What happens in iOS 27

iOS 27 keeps the same basic working model. What you learned in iOS 26 still applies: the dot layout, the main typing gestures, the idea behind Command Mode and the one-handed styles do not force you to start over.

This course uses iOS 27 as the main reference for current names, routes and behaviour. Where iOS 26 works the same way, the procedure is explained once rather than duplicated for the sake of having two paragraphs.

UEB does not change because iOS changes

Unified English Braille is the braille code; iOS is the interface that lets us enter it. Updating from iOS 26 to iOS 27 does not change the UEB dot combinations for letters, capitals, numbers or punctuation. What can change with iOS is the location of a setting, a VoiceOver gesture or the way Apple presents an option.

Braille Access

Braille Screen Input and Braille Access are separate features even though the names are easy to mix up. Braille Screen Input uses the iPhone touchscreen. Braille Access is designed around a connected braille device and provides a dedicated environment with features such as braille notes, BRF files, app launching and calculations.

Braille Access arrived with the iOS 26 generation and continues in later versions. It does not replace Braille Screen Input, and you do not need it to follow this course.

If you use iOS 26

You can follow the course normally. The alphabet, the main gestures, the two basic positions, calibration, Command Mode and one-handed input have the same foundation. Only pay special attention if a specific difference is called out.

If you use iOS 27

Follow the instructions as written. If you are coming from iOS 26, there is no need to relearn the system. After updating, test the things you actually use: start Braille Screen Input, type a few words, check space and delete, switch modes and make sure your braille table is still the one you expect.

When a later version arrives

To update this course in the future, we only need to check what genuinely changes: settings routes, option names, gestures that appear or disappear, and features that alter the way Braille Screen Input is used. Everything else can remain exactly as it is.

In short: if you already used Braille Screen Input in iOS 26 and move to iOS 27, you keep what you know. There is no new braille system waiting to make you start again from zero.
