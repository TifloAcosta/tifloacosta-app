NVDA 2026.3 is here: key improvements and add-on compatibility advice

26 October 2026 · TifloAcosta

Hello, hello, everyone!

NV Access has released the stable version of NVDA 2026.3, its free, open-source screen reader for Windows. This release brings changes you may notice in everyday use: greater responsiveness, better document reading, more braille features and expanded touchscreen gestures. There is, however, one thing worth checking before you update: your add-ons.

What is new in NVDA 2026.3?

Better performance and stability. NVDA now retrieves and caches more control information in the background to reduce lag, particularly in File Explorer and combo boxes. It is also better at recovering when an application stops responding and avoids certain crashes when the screen reader exits or restarts.

Say all by sentence, paragraph or line. A new speech setting lets you choose how Say All moves through a document. Where supported, Say All now reads by sentence by default. Sentence navigation with Alt + Up Arrow and Alt + Down Arrow is available in more documents and edit controls.

Copy the last spoken information. Press NVDA + Control + X to copy NVDA's last spoken information to the clipboard. Handy when the screen reader says something you want to keep.

Easier-to-use dialogs. The Configuration Profiles, Input Gestures and Speech Dictionaries dialogs have gained context menus and keyboard shortcuts. You can now change an existing gesture directly in Input Gestures. Browseable message windows are also easier to resize.

Web navigation. An optional native selection mode has been added for supported Firefox and Chromium-based browser documents; it is off by default. Browse mode's Find dialog can also remember previous search terms if you enable that setting.

Add-on Store fixes. Problems that could make the Add-on Store unresponsive when moving quickly through lists or searching for a single character have been addressed. Restarting NVDA after installing an add-on from File Explorer is also more reliable.

Braille, touchscreen input and text recognition

Braille users get more control over how words wrap across display lines, with continuation indicators; supported displays can also use combinations of multiple routing keys. Support for the Help Tech myBraille range and additional Liblouis tables has been added.

Touchscreen users can assign gestures made from two consecutive flicks and gestures that begin at the screen edges. Edge gestures are disabled by default and can be enabled in Touch Interaction settings.

Windows OCR can now work while Screen Curtain or NVDA's built-in Magnifier is active on supported systems. eSpeak NG has also been updated.

Will updating break my add-ons?

NVDA 2026.3 is not a general add-on compatibility-breaking release. The major change happened with NVDA 2026.1, which broke compatibility with add-ons built for NVDA 2025.3.3 and earlier. As a general rule, add-ons made compatible with NVDA 2026.1 should continue to work with NVDA 2026.2 and 2026.3. Individual problems are still possible.

This distinction matters: upgrading from NVDA 2026.2 with up-to-date add-ons is not the same as jumping straight from NVDA 2025 while relying on old extensions.

Older add-on versions worth checking

The following are specific older versions whose last-tested NVDA version in the international directory predates the 2026 series. This is not a claim that every version or similarly named alternative is incompatible.

  • Remote Support / NVDA Remote 2.6.4: last tested with NVDA 2024.1. Consider NVDA's current built-in Remote Access features or a maintained alternative such as TeleNVDA.
  • WhatsAppPlus 2.1.0: last tested with NVDA 2024.1.
  • NoBeepsSpeechMode 5.5: last tested with NVDA 2024.1.
  • zPortapapeles 0.5.1 and zRadio 0.6: old versions listed up to NVDA 2023.1. zPortapapeles is also marked as a legacy add-on.
  • Vocalizer Expressive 1.1 Driver 3.1.11: last tested with NVDA 2024.1 in the directory. If you rely on these voices, check with your voice provider for an updated driver before installing NVDA 2026.3.

A package's last-tested version is not proof of a specific failure in NVDA 2026.3. It is a warning sign that the particular package needs checking before you upgrade.

What about popular, more recent add-ons?

The directory lists Braille Extender and WordNav releases tested with NVDA 2026.1, while versions of Windows App Essentials and Resource Monitor are listed up to NVDA 2026.3. A recent TeleNVDA release is listed as tested up to NVDA 2026.2. A last-tested value of 2026.1 or 2026.2 does not automatically mean an add-on fails in 2026.3, but it does not guarantee trouble-free operation either.

What matters most is the exact version installed, how recently it was maintained and any guidance from its developer.

What to do before updating

  1. Open the NVDA menu with NVDA + N, go to Tools and open the Add-on Store.
  2. Review your installed, updatable and incompatible add-ons. Install available updates and restart NVDA when prompted.
  3. Check add-ons installed manually, particularly third-party speech synthesizer drivers, as they may not be updated through the built-in store.
  4. Back up your configuration if you have a heavily customized setup. Read any incompatibility warning carefully before proceeding.
  5. Do not override an incompatibility warning without understanding the risk: an unsupported add-on can cause errors or crashes.

After installing NVDA, restart Windows. If something goes wrong, try restarting NVDA temporarily with add-ons disabled. If the problem disappears, investigate your extensions one by one.

Downloads and further information

You can update through NVDA menu, Help, Check for update, or download the installer from the official NV Access download page.

Read the full NVDA 2026.3 release notes and check the international NVDA Add-ons Directory for individual add-on versions.

The NVDA 2026 family requires a 64-bit version of Windows 10 or Windows 11. Support for 32-bit Windows ended with NVDA 2026.1.

In short

NVDA 2026.3 includes genuinely useful improvements without imposing a fresh, blanket add-on compatibility break. If you already use NVDA 2026.2 successfully, check for add-on updates and then proceed. If your setup relies on an older add-on or a specific third-party voice, confirm its support first.

Updates are great. Finding out afterwards that your favorite add-on has taken an unexpected holiday? Not quite so great.

All the best.
