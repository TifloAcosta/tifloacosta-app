1. TifloLector: what it is and who it is for

TifloLector is the document reader and personal library built into TifloAcosta. Its purpose goes beyond reading a file aloud: it helps you find information, understand document structure, listen in the way that suits you, and return to the exact place where you stopped.

You can use it to enjoy a novel, study course notes, review a presentation, consult a spreadsheet, listen to an audiobook, or turn a document into audio to take with you. The app pays special attention to VoiceOver while offering visual options for people who read on screen.

This guide mainly describes TifloLector in TifloAcosta 1.2 for iPhone, submitted for Apple review on November 12, 2026. Features may depend on the file format, iOS version, available speech engine, and external services. Features still in development are identified explicitly.

2. Getting started: opening TifloLector and finding your way

Open TifloAcosta and select TifloLector. You will find Import, My Library, filtering and sorting controls, folders, and Settings. Your library will be empty until you import something.

With VoiceOver, move around using the usual gestures. On an adjustable control, swipe up or down with one finger to change its value. Document titles have accessibility actions, so you can perform operations without opening the book.

A good way to start is to import a TXT, EPUB, or short document, try Play, and explore Navigation Mode. You can learn the controls before moving to more complex files.

Step by step

  1. Open TifloAcosta and select TifloLector.
  2. Select Import, then From Files.
  3. Find a document in the iPhone Files app and confirm the import.
  4. Return to My Library and open the title.
  5. Select Play, or examine the text in manual mode.

3. Importing from Files and other apps

Import offers two routes: From Files and Online Libraries. From Files lets you choose documents stored on your iPhone, iCloud Drive, or other locations provided by the iOS file picker.

You can also send content to TifloAcosta using Share in another app. Received files may first appear under Received, where you can add them to TifloLector. After import, they appear in My Library.

Where the import format allows it, TifloLector retains a copy of the original file. You can then share the file as received rather than confusing it with the text version prepared for reading.

Step by step

  1. In TifloLector, select Import.
  2. Choose From Files or Online Libraries.
  3. If you choose Files, locate and select the file.
  4. Wait for it to appear in My Library.
  5. If you sent something using Share, check Received first and use the import option.

Tip: If a file does not import, check its extension and consult TifloLector Settings, Reading Formats. Not every ZIP archive or legacy Office format is supported.

4. Supported formats: much more than ebooks

Text formats include TXT, TEXT, MD, MARKDOWN, CSV, JSON, XML, LOG, and SRT. Documents and publications include EPUB, searchable PDFs and scanned PDFs processed with OCR, HTML, HTM, RTF, DOCX, ODT, and FB2. ODT and FB2 extraction focuses on text, not embedded image reproduction.

For presentations, PPTX, PPSX, and PPTM are supported. For spreadsheets, XLSX and XLSM are supported. Older PPT, PPS, and XLS files cannot yet be imported directly in this iOS version; first convert them to their modern equivalents.

The reader also recognizes text in JPG, JPEG, PNG, HEIC, HEIF, TIF, and TIFF images using OCR. Audio support includes MP3, M4A, M4B, AAC, WAV, AIF, AIFF, and CAF, as well as certain audiobook ZIP packages and DAISY books. It does not treat arbitrary RAR, 7Z, or ZIP archives as books.

Tip: You can convert an old PPS presentation to PPSX or PPTX with a compatible tool, and an old XLS spreadsheet to XLSX. Supporting a format does not mean preserving every graphic feature or formula.

5. PowerPoint presentations: turning slides into useful reading

A presentation is not necessarily designed for linear reading. When you import PPTX, PPSX, or PPTM, TifloLector extracts text from the slides, sorts it by slide number, and presents sections such as “Slide 1”, “Slide 2”, and so on.

This avoids announcing technical code or disconnected elements. You can browse the content as text, stop at a slide, add a bookmark, or use the structure the reader can detect. It is useful for classes, meetings, training, and email attachments.

This is not intelligent image description or semantic chart analysis. Information available only as an image may be missing, and the order of complex visual elements may need checking against the original.

Step by step

  1. Convert an old PPS/PPT file to PPSX/PPTX if needed.
  2. Import the presentation from Files.
  3. Open it in My Library.
  4. In the Document Outline, find slide divisions if they were recognized.
  5. Listen to the relevant slide or use Search in Document to find a word.

Tip: For a presentation you will deliver, search for key terms first and bookmark the slides you want to revisit.

6. Spreadsheets: reading figures without getting lost between cells

Reading a spreadsheet conventionally can be exhausting. For XLSX and XLSM files, TifloLector arranges extracted text by sheet, row, and column. You might hear “Sheet 1”, “Row 4”, “Column A: Product”, “Column B: Quantity”, “Column C: 25”.

This makes the data easier to follow and identifies the column associated with each value. Excel shared strings are also processed, so many text cells are read correctly instead of exposing internal identifiers.

The feature helps you consult and listen to tabular information; it does not replace a spreadsheet editor. Do not assume it can explain formulas, reproduce charts, retain cell formatting, or interpret complicated relationships between tables.

Step by step

  1. Save the spreadsheet as XLSX or XLSM; convert old XLS files first.
  2. Import it into TifloLector.
  3. Open the document and listen to each sheet heading.
  4. Move through document blocks or use Search to find a concept, number, or name.
  5. Bookmark a useful row if you return to it often.

Tip: For large sheets, learn the original column headings before listening to the data. Linear reading is an accessible representation, not interactive Excel editing.

7. Scanned PDFs and images: recognizing printed text

Not all PDFs contain selectable text: some are simply photographs of pages. TifloLector uses optical character recognition (OCR) for scanned pages with no text and can also recognize text in supported images.

Under TifloLector Settings, OCR and Recognition, you can choose the recognition language and a preference for accuracy or speed. The setting applies to later imports; it does not automatically reprocess documents already imported.

Results depend on scan quality. Skewed or blurry photographs and complex tables may produce errors. As a safeguard, PDF OCR import is limited to 150 scanned pages per file. Split larger documents before importing.

Step by step

  1. Open TifloLector Settings, then OCR and Recognition.
  2. Choose the appropriate language and accuracy settings.
  3. Import the scanned PDF or image.
  4. Open the result and review a sample of the recognized text.
  5. If you find errors, try a better scan or split the file.

8. Online libraries and OPDS catalogs

Under Import, choose Online Libraries. You can browse Project Gutenberg and add public OPDS catalogs using HTTPS, including OPDS 1 (Atom) and OPDS 2 (JSON).

Browse results, search by title or author using catalog features, and choose “Import to My Library” when a book offers a compatible download. The book then becomes part of your personal library.

The Bookshare option currently opens its website; direct integrated downloading requires the account and authorization rules of that service. Showing a library in the menu does not mean all its books are freely accessible.

We are discussing a possible integration with the Tiflonexos library, with the aim of making authorized access accessible. As of this guide, Tiflonexos is not integrated or available through TifloLector. Any agreement and working solution will be announced through official TifloAcosta channels.

Step by step

  1. Select Import, then Online Libraries.
  2. Choose Project Gutenberg to explore public-domain books.
  3. To use another compatible catalog, select Add OPDS Catalog.
  4. Enter a name and HTTPS address, then save it.
  5. Open a result, check the offered format, and select Import to My Library if available.

Tip: Check each library’s access, copyright, and download conditions. A catalog listing does not guarantee a compatible downloadable edition.

9. My Library: finding, sorting, and organizing documents

My Library holds documents of different kinds in one place. Filter Documents offers All, Text, PDF, EPUB, Office, Audio and DAISY, With Bookmarks, Favorites, Imported Today, Last Seven Days, and Last Month.

Sort offers Newest First, Oldest First, Title A to Z, Title Z to A, Format, and Last Opened. Use View by Folders to create folders and move documents without modifying the original file stored in the system.

Selection allows bulk operations: select all visible items, deselect them, move them into a folder, delete them, or add or remove them from Favorites.

Accessible title actions include Play, Share Original Document, Information, Document Settings, Move to Folder, Add to Favorites, Rename, Translate, and Delete. VoiceOver may announce varying detail about a document, from its title and reading percentage to its format and folder.

Step by step

  1. Find Filter Documents and select, for example, Office.
  2. Use Sort and select Last Opened.
  3. Open View by Folders and create a folder for study or work materials.
  4. On a document title, use VoiceOver rotor actions to move it, rename it, or view information.
  5. For several documents, activate Selection, mark the items, and choose the operation.

Tip: Before deleting multiple documents, verify the active filter and the number of selected items.

10. Playing, pausing, and resuming without losing your place

Inside each document you will find Play or Pause along with movement controls. Under TifloLector Settings, Reading Mode, choose whether playback starts automatically when you open a document or waits for you to select Play.

Your reading position is saved for later. Bookmarks store useful places independently of the most recent reading position. For recorded audio, playback controls adapt to the available tracks.

Background playback depends on the content and speech engine. Behavior when the screen locks may differ between recorded audio, system voices, and external services.

Step by step

  1. Open a book from My Library.
  2. If manual mode is enabled, select Play.
  3. Select Pause whenever you want to stop.
  4. Return to My Library and reopen the title to resume from the stored position.
  5. Use Information to check the percentage read and, where available, timing information.

11. Advanced navigation: more than just turning pages

One of TifloLector’s most useful controls is Navigation Mode. Depending on the document and its structure, you can move by block, paragraph, sentence, page, heading, time, bookmark, link, chapter, or—in compatible DAISY books—DAISY page or reference.

Navigation units that do not apply to a particular file may be absent. A document without detectable headings will not offer exactly the same options as a DAISY book with a structured contents list.

To change units, locate Navigation Mode and swipe up or down with VoiceOver. The playback control offers adjustable actions for moving forward or backward by the selected unit. Document Outline groups headings, pages, slides, spreadsheet sheets, and DAISY navigation points when available.

There is also Go to Position, using percentages from 0 to 100, and a Time Interval setting with 30 seconds, 1 minute, 2 minutes, and 5 minutes, especially useful for audio.

Step by step

  1. Open a book containing several chapters.
  2. Find Navigation Mode and select Chapter or Heading if available.
  3. Swipe on the adjustable playback control to move backward or forward.
  4. Choose Outline and Structured Navigation to jump to a particular point.
  5. For an approximate jump, use Go to Position and choose a percentage.

Tip: For studying, combine chapters, headings, and bookmarks. Percentage jumps are approximate; a document’s own structure is generally more accurate.

12. Searching within a document and returning to where you were

Search in Document finds a word or phrase within the work you are reading. Instead of traversing hundreds of paragraphs, search for a term and move directly to a matching result.

TifloLector includes a way to return to your reading position before the search, so looking something up does not permanently interrupt your place. This is valuable for manuals, coursework, and reference books.

Step by step

  1. Open the document.
  2. Select Search in Document.
  3. Type a term and review the results.
  4. Open the match you want.
  5. Use Return to Position Before Search to continue where you left off.

13. Bookmarks: saving important places without interrupting speech

A bookmark stores a particular position. It need not be the place where you most recently stopped reading. You can save several bookmarks, view them under Saved Bookmarks, return to each one, and delete them individually.

In text documents, bookmarks may retain a reference to the associated passage. In audio they may identify the track and percentage. VoiceOver can provide confirmation when a bookmark is created.

You can create bookmarks using Add Bookmark inside the reader, the Create Bookmark VoiceOver rotor action, or an iOS shortcut designed to work without stopping playback.

Under TifloLector Settings, Quick Bookmark Creation, you will find instructions for installing the “Bookmark Reading” shortcut. Add it to Shortcuts and, on compatible iPhones, assign it to Back Tap (triple tap) or the Action button. You configure the gesture in iOS Settings; TifloLector does not impose it automatically.

Step by step

  1. Open a book and start listening.
  2. Focus the reading element and choose Create Bookmark from VoiceOver actions, or select Add Bookmark.
  3. For quicker access, open Settings, Quick Bookmark Creation, and install the suggested shortcut.
  4. If convenient, assign the shortcut to Back Tap or the Action button in iPhone Settings.
  5. Open Saved Bookmarks to return to a particular point.

Tip: For studying, bookmark the start of each topic and any questions you want to revisit.

14. System voices, additional voices, and Personal Voice

By default, you can use the speech voices provided by iOS. In TifloLector Settings, Audio and Voices, select System Voices, browse the available options, and choose the voice you prefer.

Find More Voices guides you through iPhone Settings to download additional voices. Once installed, return to TifloLector and refresh the list. Exact availability depends on language and iOS version.

On compatible devices, you can also request permission to use a Personal Voice already created in iOS. TifloLector does not create that voice itself; voice creation is managed by the operating system.

Step by step

  1. Open TifloLector Settings, then Audio and Voices.
  2. Choose System Voices as the reading engine.
  3. Select your preferred voice.
  4. To get additional voices, choose Find More Voices and follow the steps in iOS Settings.
  5. Return to TifloLector; if using Personal Voice, grant permission where the device supports it.

15. Gemini and Phonon: external speech engines

In addition to system voices, TifloLector has an External Engines section containing Gemini and Phonon. Each has a separate screen so credentials, models, and settings are not mixed up.

Gemini uses Google services and requires each person to obtain and store their own API key. TifloAcosta provides an accessible guide: choose Create API Key with Guide, open Google AI Studio, sign in if needed, create and copy a key, then choose Paste and Save on returning to the app. Test Connection checks whether the key works. Never share or publish your key.

Gemini usage may count against a quota and be subject to Google’s terms and charges. TifloAcosta does not provide a shared key or cover usage. You can test Gemini voices and select them for reading or exporting.

Phonon is intended for local voices and does not require an API key, but it needs a compatible engine and installed models. The current version provides options to download or import compatible Core ML models. Use depends on licenses, language, native-engine availability, and sometimes iOS 18 or later. Simply installing a separate Phonon app does not automatically activate Phonon inside TifloLector.

Step by step

  1. Open TifloLector Settings and select External Engines.
  2. For Gemini, open Gemini and select Create API Key with Guide; follow the accessible steps.
  3. Paste the key, select Save, then Test Connection; select a voice and play its sample.
  4. Return to Audio and Voices and choose Gemini once it has been configured successfully.
  5. For Phonon, open its section, check compatibility, install a supported model, and play a sample before selecting it.

Tip: System voices are the easiest place to begin: they do not require API keys. Check external services’ terms and quotas before using them.

16. Customizing speech: speed, pitch, and punctuation pauses

People do not all understand fast, deep, or minimally paused voices equally well. TifloLector therefore allows separate adjustments to speed, pitch, and punctuation pauses for system-voice reading.

Speed ranges from 0.75× to 1.50× in small 0.05 increments. Pitch offers five levels: Lower, Low, Normal, High, and Higher. Change these settings with VoiceOver adjustable-control gestures without entering numbers.

Punctuation Pauses offers Normal, Longer, Expressive, and Custom profiles. Under Custom, you can specify pauses after commas, semicolons, colons, periods, question or exclamation marks, and paragraph breaks. Values range from 0 to 1.50 seconds in 0.05-second steps.

These added pauses are implemented specifically for system voices. They do not alter a prerecorded audiobook or guarantee the same rhythm with Gemini or Phonon.

You can set general preferences or use different settings for a particular work. A technical manual can be read more slowly while a novel keeps a livelier pace.

Step by step

  1. Open Settings, Audio and Voices.
  2. Select Speech Speed and adjust gradually with up or down swipes.
  3. Try Reading Pitch to find a comfortable level.
  4. Under Punctuation Pauses, first listen to Normal, Longer, and Expressive.
  5. For finer control, choose Custom and adjust each punctuation mark separately.
  6. For an individual title, open Document Settings to set its own preferences.

Tip: For formulas, lists, and academic material, longer pauses can improve comprehension. Choose settings based on the content and your needs.

17. Visual presentation and reading mode

TifloLector includes visual settings such as text size, line spacing, and enhanced text emphasis. These can help people who combine on-screen reading with speech or magnification.

Manual mode opens a document without speaking automatically. Automatic mode starts playback when the document opens. Your preference remains in effect until you change it.

You can also customize general app contrast and presentation options on the iPhone.

Step by step

  1. Open TifloLector Settings, then Visual Settings.
  2. Choose a suitable font size and spacing.
  3. To explore the document with VoiceOver before playback, open Reading Mode and select Manual.
  4. For immediate speech when opening books, select Automatic.

18. Sleep timer and comfortable listening controls

Auto Stop can stop playback after a chosen period. The available intervals are Off, 5, 10, 15, 30, 45, and 60 minutes.

This is useful when listening to a novel before bed or setting aside a fixed study period. Forward and backward controls help you locate a point without traversing the whole work.

Step by step

  1. Open the book and find Auto Stop.
  2. Select an interval, such as 15 minutes.
  3. Start listening.
  4. To continue, review or change the timer using the same control.

19. Translating a complete document while preserving the original

The Translate feature in version 1.2 is available through accessibility actions on a text-document title in My Library. It aims to translate an entire work, not just a sentence or short excerpt.

The target languages are Spanish, English, Portuguese, French, Italian, and German. TifloLector splits the content into sections, shows progress, and saves a translated copy as a new library item. It does not overwrite the original.

The feature uses translation technology available in iOS 18 or later. Depending on the language pair, system resources, language downloads, or service availability may be required. Audio-only content does not automatically include translatable text. Check proper names and specialist terminology before treating a translation as definitive.

The reader also offers a separate Translate Current Excerpt option for quick lookups when supported by the content and operating system.

Step by step

  1. In My Library, focus the title of a text document.
  2. Open its VoiceOver accessibility actions and choose Translate.
  3. Choose the target language.
  4. Select Translate Document and monitor the progress.
  5. When complete, open the translated copy saved to My Library.

Tip: If you study in another language, keep both versions so you can compare important terms.

20. Dictionary, pronunciation, and links

Document actions may include Dictionary and Pronunciation when there is suitable text to look up. This helps clarify a word without fully leaving the reading experience.

For documents containing recognized links, Links may appear as a navigation unit together with an action to open the current link. It is useful for technical manuals, HTML articles, and publications with references.

These options depend on the structure preserved from the source. Not every file contains navigable references.

Step by step

  1. Focus a passage you want to investigate.
  2. Open Actions and choose Dictionary and Pronunciation, if offered.
  3. To browse references, change Navigation Mode to Links, where available.
  4. Use Open Current Link on the appropriate link.

21. Creating audiobooks: MP3, M4A, WAV, and DAISY

TifloLector can do more than read text aloud: it can generate audio files you can share or use outside the app. Export options include MP3, M4A, WAV, and DAISY, depending on the content and available engine.

DAISY export is not merely an MP3 with a different extension. DAISY 3 generation includes structured text, audio files, paragraph-level synchronization using SMIL, and an NCX navigation index. The package is checked before it is shared.

This can be particularly valuable for studying and technical references. A continuous audio file works for a novel, while a compatible DAISY book can let you jump between sections or passages without starting from the beginning. Exact navigation depends both on the exported package and the DAISY player.

You can generate narration using system voices and, when configured, compatible external engines. The 60,000-character limit applies to exports through the Gemini API, not generally to local system voices. Generation time and any cost depend on the engine, document length, and storage requirements.

When exporting DAISY, select the actual language of the book’s content. The exported file name is based on the work’s title rather than an unnecessary technical identifier.

Step by step

  1. Open a document containing text.
  2. Select Actions, then Export Audio MP3 or DAISY.
  3. Choose the format: MP3, M4A, WAV, or DAISY.
  4. Choose the speech engine and its voice, where applicable.
  5. For DAISY, specify the actual language of the book.
  6. Select Generate and Share, check progress, and let the process finish.
  7. Save the package or share it with your chosen app.

Tip: Try DAISY for manuals with chapters and paragraphs; MP3 is usually simpler for listening in an ordinary audio player. Always verify the finished output before distributing it.

22. Reading DAISY audiobooks and audio packages

TifloLector can import DAISY ZIP packages and files with a DAISY extension, along with ZIP archives containing recognizable audio tracks. An audiobook ZIP is not necessarily a DAISY book: the former simply groups tracks, while the latter may provide a navigable structure.

In compatible DAISY books, TifloLector may display chapters, pages, and references from the package’s navigation data, as well as text and audio tracks where present. Full SMIL navigation for every kind of DAISY package is still being developed, so universal DAISY compatibility must not be assumed.

For multi-track recordings, you can select a track, move backward and forward, and save bookmarks associated with its position. Depending on the content, you can also share an audio file or all tracks together as a ZIP.

Step by step

  1. Import the DAISY book or audio ZIP from Files.
  2. Open the work and check whether tracks, text, or DAISY navigation elements appear.
  3. Use Navigation Mode to move among chapters, pages, or references where available.
  4. Bookmark useful places and consult the contents list if the book has one.

23. Sharing, recovering the original, and exporting text

In a title’s library actions, Share Original Document sends the file you originally imported rather than the text extracted for reading. Inside the work, Export Text may also be available to create a TXT file from the readable content.

Audio documents offer additional track-sharing options, while text documents can be exported as MP3 or DAISY. Each serves a different purpose: keeping the source file, obtaining plain text, or creating an audiobook.

Step by step

  1. Open the title actions in My Library.
  2. Choose Share Original Document to send the imported file as it was.
  3. To obtain a TXT, open the document and choose Actions, Export Text.
  4. To create audio, choose Export Audio MP3 or DAISY and select the format.

24. Backing up and restoring your library

The library offers Export Backup and Restore Backup. A backup can include document records, original files, media, folders, reading positions, and bookmarks.

This is useful when changing devices, safeguarding a personal collection, or protecting your work organizing and reading documents. Restore is designed to add missing items rather than automatically replace items already present.

A backup is not the same as continuous device synchronization. Store the exported file somewhere safe and check periodically that you can find it.

Step by step

  1. In TifloLector, open More Options.
  2. Select Export Backup.
  3. Save the file in Files or another trusted storage location.
  4. To recover it, choose Restore Backup and select the saved package.
  5. Confirm that the expected documents, folders, and bookmarks are present.

Tip: Keep the backup outside the app—for example, in Files or iCloud Drive—so it remains available even if you remove TifloAcosta.

25. Four practical ways to make the most of TifloLector

For studying: import your notes as EPUB, PDF, or DOCX; choose a clear voice with longer pauses; navigate by chapters or headings; bookmark difficult concepts; and use Search to revise particular terms.

For an emailed presentation: save it as PPTX or PPSX, import it, and listen to the contents organized by slide. Bookmark points you may need to find quickly while presenting.

For a budget or long list: open the XLSX or XLSM and use sheet, row, and column references. Search for names or numbers and return to the section you need.

For turning a manual into an audiobook: make sure the document contains text, check its structure, choose a voice, and export it as DAISY to preserve navigation or as MP3 for an ordinary player.

26. Important limitations before you begin

Do not assume every legacy Office file imports directly: old PPS/PPT and XLS files still require conversion. Presentations with many images and spreadsheets with complex charts or formulas may lose information when transformed into linear text.

OCR depends on source quality. Whole-document translation depends on iOS 18 or later and language-pair support. External speech engines have their own requirements, licenses, or usage quotas. DAISY navigation depends on package structure.

Tiflonexos is a prospective integration, not a currently integrated service. Users must follow each provider’s permissions and conditions for protected content.

This guide reflects the code prepared for TifloAcosta iOS 1.2. Some features may differ or not yet exist on Android, older iOS releases, or the web app. While Apple is reviewing 1.2, it should not be confused with the version already publicly available on the App Store.

27. Frequently asked questions

Do I need an API key to use TifloLector? No. System voices work without Gemini. You only need a key to connect the corresponding external service.

Is DAISY the same as MP3? No. DAISY may include audio, synchronized text, and navigable structure; an ordinary MP3 does not provide these features by itself.

Can I open an old PPS or XLS file? Convert it to PPSX/PPTX or XLSX, respectively, before importing it in the iOS version described here.

Can I translate a book and keep the original? Yes, when the book has text and translation is available on your device. The app creates a separate library item.

Is Tiflonexos already in Online Libraries? No. Discussions are ongoing, but integration is not complete.

What happens when I close a book? The reader saves the reading position and bookmarks, although precise options can depend on the document type.

Can I listen to a scanned PDF? Yes, if OCR successfully recognizes its text. Review the output for possible errors.

28. An invitation to try it with your own documents

TifloLector aims to make a document adapt to your needs, not the other way around. Reading a novel is different from studying course material, preparing a class, or consulting a table. That is why the reader offers different voices, speeds, pauses, navigation units, and output formats.

Start with a document you know well. Try bookmarks, change the navigation unit, adjust the voice, and, if useful, create a DAISY file. You will discover the best combinations by testing what makes reading easier for you.

This guide will support a series of TifloAcosta tutorials and accessible educational videos. Future features and libraries will only be announced when they are available.
