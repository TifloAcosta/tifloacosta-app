This Shortcut Doesn’t Ask Questions: It Sees a Code and Starts Investigating

Accessible written adaptation of the TifloAcosta video, prepared so the content can be followed without needing to see or hear the recording.

Watch the original video on YouTube

Introduction

In this video, Tony Acosta explains different ways to read QR codes and barcodes on an iPhone with VoiceOver.

He first shows how to use the iPhone Camera app itself to detect a QR code that is physically in front of you. He then moves on to a different problem: what happens when the code is already inside the phone, for example in a photo or screenshot someone has sent you.

To solve that second situation, he introduces a shortcut called «leer código» — “read code” — which is designed to analyze images containing QR codes or barcodes and then act on the information it finds.

The aim is to discover what a code contains without needing a second phone to scan the screen. With barcodes, the shortcut can also use the detected number to search the Internet and try to identify the product.

Preparing the iPhone Camera to read QR codes

Before starting, Tony checks that QR code recognition is enabled on the iPhone.

He opens Ajustes (Settings), goes into Cámara (Camera), and finds «Escanear códigos QR» (Scan QR Codes).

This switch needs to be enabled. Tony explains that if it is turned off, the Camera app will not detect a QR code even if you point the phone at it correctly.

Reading a QR code in front of you

With that setting enabled, Tony opens Cámara (Camera) and points the iPhone at a QR code.

The Camera app detects it quickly.

Once the code has been recognized, the associated content can be opened.

After the demonstration, Tony closes the Camera app and explains that he does so to avoid leaving it running and unnecessarily using battery power.

What if the QR code is already inside the iPhone?

This is the situation that led Tony to create the shortcut.

Someone may send you a photo or screenshot containing a QR code. In that case, using the same iPhone camera to scan something already stored on the phone is not practical.

Tony therefore created a shortcut called «leer código» (“read code”).

The shortcut can receive an image, analyze it, and extract the content of any supported code it finds.

Reading a QR code saved in Photos

Tony opens Fotos (Photos) and selects an image containing a QR code.

He activates Compartir (Share) and, in the iOS share sheet, locates the shortcut «leer código» (“read code”).

When he runs it, the shortcut analyzes the image.

In this first example, it finds an Internet address that leads to an app in the App Store.

The detected content is shown before continuing. After Tony confirms it, the link opens and the iPhone displays the corresponding App Store page.

This makes it possible to receive a QR code on the same phone and find out where it leads without using a second device.

What the shortcut does with the information it finds

The shortcut behaves differently depending on the content stored in the code.

If the code contains a web address, the shortcut can open that link.

If the result is not a web address — for example, the number extracted from a barcode — the shortcut uses that content to run an Internet search.

The same shortcut can therefore be used with both QR codes and barcodes.

First barcode test

Tony tests the shortcut with a product barcode.

He opens Cámara (Camera) and takes a photo of the barcode.

He then goes to Fotos (Photos), locates the new image, activates Compartir (Share), and runs «leer código» again.

This time, the detected content is not a web address but the numeric barcode value.

The shortcut uses that number to search the Internet.

The search results identify the product as Aposán single-dose physiological saline, 5 ml.

The demonstration shows that the shortcut does more than expose the barcode number: it uses the number to try to find useful information about the product.

Second test: the barcode on a book

Tony performs another test using a barcode associated with a book.

The first photo does not capture the code well enough. Tony uses this failed attempt to make an important point: if the barcode is not sufficiently clear in the photo, the shortcut may not find anything.

The practical solution is to take another photo and try to frame the code better.

Tony repeats the shot, opens the new photo in Fotos (Photos), activates Compartir (Share), and runs «leer código» again.

This time the code is recognized and the corresponding search is performed.

Among the results is the book «La vida vista desde donde estoy» (“Life Seen from Where I Am”).

Tony naturally takes the opportunity to recommend it.

What you need to use «leer código»

The shortcut uses actions that are not built into Apple’s Shortcuts app, so it requires an additional app called Actions.

Actions is free.

Download Actions from the App Store

After installing it, it is a good idea to open Actions at least once so that its actions become available to the Shortcuts app.

Restarting the iPhone is only recommended if those actions do not appear in Shortcuts afterwards.

You do not need to restart the device every time the app is installed.

Once Actions is ready, install Tony’s shortcut here: Install «leer código» (“read code”)

A tool that lets the iPhone do the investigating

The main advantage of the shortcut is that you do not need to know in advance exactly what kind of code you are dealing with.

It can receive an image containing a QR code, extract its web address and open it, or obtain the number from a barcode and use the Internet to investigate what that number represents.

It is particularly useful when the code is in a photo or screenshot already stored on the iPhone, where directly scanning it with the same phone’s camera would not be practical.

Closing

Tony hopes both the shortcut and the explanation are useful and help people get more out of the iPhone when working with QR codes and barcodes independently.
