Make Your iPhone Speak When Charging: Play a Sound When Connecting or Disconnecting the Charger

Accessible written version of a Canal TifloAcosta video.

Introduction

Tony Acosta presents an iOS automation on Canal TifloAcosta that makes the iPhone automatically play an audio file whenever the charger is connected or disconnected.

Preparing the sound file

Before creating the automation, Tony explains that the audio file to be used as the alert must already be available.

He opens the Files app and goes to iCloud Drive. Inside that location he opens the “Shortcuts” folder and places the sound file used in the demonstration there.

The file is identified as “carga.mp3”. Tony stresses that, when the file path is entered later in the shortcut, the name and extension must match the stored file exactly so that it can be found correctly.

Opening the Automation section

Tony opens the Shortcuts app and selects the “Automation” tab in the bottom bar.

On the automation screen he activates “New Automation”. The list of available triggers opens and he selects “Charger”, which VoiceOver identifies as the option related to the iPhone being connected to power.

Choosing when it should run

Under the charger options, “Is Connected” is selected initially. Tony also enables “Is Disconnected” so that the same automation runs both when the charger is connected and when it is removed.

For the execution method, he changes “Run After Confirmation” to “Run Immediately”, so no manual confirmation is required each time.

“Notify When Run” remains disabled to avoid an additional notification whenever the automation is triggered.

He then activates “Next”.

Creating the automation actions

On the following screen Tony activates “New Blank Automation”.

During the demonstration he notes that, if VoiceOver has difficulty activating this control, Screen Recognition from the VoiceOver rotor can be used to make the control interactable.

Inside the editor, he activates “Search Actions” and types “Get File from Folder”.

From the results he selects the action corresponding to getting a file from a folder. The automation then shows a structure that retrieves a file from the Shortcuts folder using a specified path.

Tony uses VoiceOver rotor actions on that instruction to reach the option for editing the path. In the path field he enters “carga.mp3”, matching the file previously stored in the Shortcuts folder.

Adding sound playback

Tony returns to “Search Actions” and types “Play Sound”.

He selects the “Play Sound” action from the results. The automation is therefore made up of one action that retrieves the stored file and another that plays it.

To finish, he activates “OK” and then “Add” to save the automation.

Practical test

Tony tests the finished automation.

He first disconnects the earphone that was plugged into the phone. He then connects the charger cable to the iPhone. The automation runs immediately and plays the configured sound.

He disconnects the charger afterwards, and the iPhone runs the automation again and plays the same sound alert.

Conclusion

Tony finishes the demonstration by inviting viewers to leave comments, like the video, and share it. He says goodbye until the next Canal TifloAcosta video.
