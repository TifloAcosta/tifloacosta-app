Curso práctico de WhatsApp Desktop en Windows

Con lectores de pantalla: JAWS y NVDA

Introducción general

WhatsApp se ha convertido en una herramienta imprescindible en el día a día de millones de personas. Sin embargo, su uso en el ordenador sigue siendo, para muchas, un terreno poco explorado, y más aún cuando se utilizan lectores de pantalla.

Este curso nace con un objetivo claro: ofrecerte una guía práctica, completa y accesible para que cualquier persona pueda usar WhatsApp Desktop en Windows con JAWS o NVDA partiendo desde cero.

No se da nada por sabido. Cada paso está pensado para ser comprendido y aplicado, incluso por quien nunca ha utilizado esta plataforma en un ordenador. A lo largo de los módulos se trabaja con ejemplos reales, ejercicios guiados y explicaciones claras, con el propósito de que no solo se aprenda la herramienta, sino que se adquiera seguridad en el uso diario.

El objetivo final no es conocer WhatsApp, sino manejarlo con soltura y criterio.

Módulo 0. Conceptos previos y requisitos

Antes de instalar nada, conviene entender qué se va a usar exactamente. Muchas dificultades que aparecen después no tienen que ver con el lector de pantalla, sino con no tener claro cómo funciona WhatsApp en un ordenador. Este módulo resuelve eso antes de dar el primer paso.

¿Qué es WhatsApp Desktop?

WhatsApp Desktop es la aplicación oficial de WhatsApp para ordenadores con Windows. Permite usar la cuenta de WhatsApp desde el PC sin depender del navegador. No es una cuenta distinta, sino la misma que se tiene en el móvil, sincronizada en tiempo real.

Diferencia entre WhatsApp Desktop y WhatsApp Web

WhatsApp Web funciona dentro de un navegador como Chrome o Edge, mientras que WhatsApp Desktop es un programa independiente que se instala en el ordenador. Desde el punto de vista de la accesibilidad, la versión Desktop suele ser más estable con los lectores de pantalla, especialmente con NVDA. Con JAWS también funciona bien, aunque dependiendo de la versión puede haber pequeñas diferencias de comportamiento.

Requisitos necesarios

Antes de continuar, hay que cumplir estos puntos:

  • Tener un ordenador con Windows 10 o superior.
  • Tener conexión a Internet activa.
  • Tener WhatsApp instalado y funcionando en el móvil.
  • Saber desbloquear el móvil y moverse por sus ajustes básicos.

Concepto clave: dispositivos vinculados

WhatsApp Desktop no funciona de manera independiente. Necesita vincularse con el móvil mediante un código QR la primera vez que se configura. Esto significa que no se crea una cuenta nueva, no se introduce usuario ni contraseña, sino que se escanea ese código con el móvil y, a partir de ahí, el ordenador queda autorizado como dispositivo de confianza.

Ejemplo práctico

Piensa en el ordenador como una extensión del móvil. Todo lo que se hace en uno aparece en el otro: si se envía un mensaje desde el PC, aparece también en el móvil; si se recibe uno en el móvil, aparece en el PC. Ambos funcionan en sincronía.

Ejercicio del módulo

Comprueba lo siguiente:

  • Abre WhatsApp en tu móvil.
  • Verifica que puedes enviar y recibir mensajes sin problemas.
  • Localiza en los ajustes del móvil la opción «Dispositivos vinculados».

Si no encuentras esa opción, no continúes. Ese punto es imprescindible para el siguiente módulo.

Resultado esperado

Al terminar este módulo debes tener claro qué es lo que va a instalar, que no se trata de una cuenta nueva y que el móvil es necesario sí o sí para empezar. Si alguno de estos puntos no está claro, todo lo demás se complica de manera innecesaria.

Módulo 1. Descarga e instalación en Windows

Aquí es donde mucha gente falla por ir deprisa y descargar lo primero que aparece en un buscador. Vamos a hacerlo correctamente desde el principio para evitar sorpresas.

Opciones de descarga

Hay dos formas principales de instalar WhatsApp en Windows:

  • Desde la Microsoft Store.
  • Desde la web oficial de WhatsApp.

Para usuarios de lectores de pantalla, lo más recomendable es descargar desde la web oficial. La versión de la tienda funciona, pero en ocasiones introduce cambios que afectan a la accesibilidad y que tardan más en corregirse.

Descarga desde la web oficial

Sigue estos pasos:

  • Abre tu navegador habitual, ya sea Edge o Chrome.
  • En la barra de direcciones, escriba whatsapp.com y pulse Intro.
  • Una vez cargada la página, busque el enlace de descarga para Windows, que suele aparecer como «Descargar para Windows».
  • Pulsa Intro sobre ese enlace.

El archivo se descargará automáticamente. Normalmente tendrá extensión .exe y se guardará en la carpeta Descargas, a la que puede acceder con Windows + E y navegando hasta esa ubicación.

Instalación del programa

Una vez localizado el archivo descargado:

  • Pulsa Intro sobre él.
  • Si Windows pide confirmación de seguridad, acéptela.

El instalador se ejecutará automáticamente y no requiere intervención adicional. WhatsApp se instala casi sin necesidad de que el usuario haga nada, y en unos segundos la aplicación se abrirá sola.

Primer arranque

Al abrirse por primera vez, aparecerá una pantalla con un código QR. El lector de pantalla lo anunciará como imagen o como código. Esto es completamente normal y no indica ningún error: significa que el programa está listo para vincularse con el móvil.

Errores comunes

  • Descargar desde páginas no oficiales, que pueden incluir software no deseado.
  • Pensar que hay que crear una cuenta nueva antes de instalar.
  • Cerrar la aplicación al ver el código QR creyendo que algo ha fallado.

Nada de eso. Si se ve el código QR, todo está funcionando correctamente.

Ejercicio del módulo

  • Descarga WhatsApp desde la web oficial.
  • Instálalo siguiendo los pasos descritos.
  • Ábrelo y deje visible la pantalla con el código QR.

Resultado esperado

Al terminar este módulo debes tener WhatsApp instalado en el ordenador, la aplicación abierta y el código QR listo para ser escaneado. Si ha llegado hasta aquí sin problemas, ya tiene la parte más técnica resuelta. Lo siguiente es vincular la cuenta, que es donde suele aparecer el primer bloqueo real en usuarios nuevos.

Módulo 2. Vincular WhatsApp del móvil con el ordenador

En este punto ya tiene WhatsApp Desktop abierto en el ordenador mostrando un código QR. Ese código no se escribe, no se copia y no se dicta. Se escanea con el móvil. Si se intenta hacer cualquier otra cosa, se perderá el tiempo.

¿Qué es el código QR en este contexto?

El código QR es una forma rápida de autorizar el ordenador para usar la cuenta de WhatsApp. No contiene mensajes ni datos personales, y no es peligroso. Solo sirve para conectar ambos dispositivos de forma segura.

Pasos desde un iPhone con VoiceOver

  • Abra la aplicación de WhatsApp en el iPhone.
  • Busque la pestaña «Configuración», que normalmente se encuentra abajo a la derecha.
  • Pulsa sobre ella y, dentro, busque la opción «Dispositivos vinculados».
  • Pulsa dos veces para entrar.
  • Dentro de esa pantalla, busque «Vincular un dispositivo» y pulse dos veces.

En ese momento se activará la cámara del iPhone y VoiceOver indicará algo similar a «Apunta al código QR».

Pasos desde un Android con TalkBack

  • Abra WhatsApp en el móvil Android.
  • Pulsa en el icono de los tres puntos o en el menú principal.
  • Busque la opción «Dispositivos vinculados» y pulse dos veces sobre ella.
  • Pulsa en «Vincular un dispositivo».

La cámara se activará del mismo modo que en iPhone. El proceso de escaneo es idéntico en ambos sistemas.

Escaneo del código

Una vez activa la cámara, apunte con el móvil hacia la pantalla del ordenador donde está visible el código QR. No hace falta tocar nada más. En cuanto la cámara detecta el código, el proceso se realiza automáticamente, sin botón de confirmar ni ninguna acción adicional.

Si todo va bien, en pocos segundos WhatsApp Desktop se cargará con todas las conversaciones.

¿Qué ocurre después de vincular?

Una vez completada la vinculación, aparecerán los chats en el ordenador y el lector de pantalla comenzará a leer la lista de conversaciones. El móvil puede quedar en segundo plano: no es necesario tenerlo desbloqueado de manera continua para que el ordenador funcione.

Errores comunes

  • Mover demasiado el móvil y no dejar que la cámara enfoque bien.
  • Pensar que hay que hacer algún gesto adicional sobre el código.
  • No encontrar «Dispositivos vinculados» en los ajustes del móvil.
  • Tener la cámara tapada o con poca luz.

Si no funciona a la primera, mantén el móvil quieto unos segundos frente a la pantalla y espere. El escaneo ocurre solo.

Ejercicio del módulo

  • Abra WhatsApp Desktop en el ordenador.
  • Accede en el móvil a «Dispositivos vinculados».
  • Pulsa en «Vincular un dispositivo».
  • Escanea el código QR apuntando con la cámara a la pantalla del ordenador.

Resultado esperado

Al terminar este módulo debes ver WhatsApp Desktop mostrando sus conversaciones y el lector de pantalla leyendo la lista de chats. Si aparecen los chats, está hecho. No hay medias tintas en este punto.

Módulo 3. Interfaz general de WhatsApp Desktop

Aquí empieza el manejo real. Si se entiende bien la estructura de la aplicación, todo lo demás fluye con naturalidad. Si no, cada acción se convierte en una lucha innecesaria.

Estructura general

La ventana de WhatsApp Desktop se organiza en tres zonas principales que hay que conocer y distinguir desde el principio:

  • Zona izquierda: la lista de chats.
  • Zona central: la conversación activa.
  • Zona inferior dentro de la conversación: el campo de escritura.

Zona izquierda: lista de chats

Aquí aparece la lista de todas las conversaciones, tanto chats individuales como grupos, junto con indicadores de mensajes no leídos. Para moverse por ella se usan las flechas arriba y abajo, y el lector de pantalla irá leyendo el nombre de cada conversación.

Zona central: conversación activa

Cuando se abre un chat, en esta zona central aparecen los mensajes enviados y recibidos, con sus indicadores de hora y el nombre del contacto o del grupo. Para navegar entre mensajes se usan las flechas, y también es posible usar los comandos de lectura continua del lector de pantalla.

Zona inferior: campo de escritura

Aquí se escriben los mensajes. Incluye el campo de texto, el botón de enviar y opciones adicionales como adjuntar archivos o grabar audio. Para llegar hasta este campo desde la lista de chats hay que pulsar la tecla Tabulador varias veces.

Navegación básica con teclado

Las teclas fundamentales para moverse por la aplicación son las siguientes:

  • Tabulador: avanza entre zonas y elementos interactivos.
  • Shift + Tabulador: retrocede.
  • Flechas: navega dentro de listas o entre mensajes.
  • Intro: abre o activa el elemento seleccionado.

Comportamiento con JAWS

JAWS puede alternar entre cursor virtual y cursor PC. En WhatsApp Desktop suele funcionar mejor el cursor PC, ya que la aplicación está construida como una interfaz web interna. Si algo no responde como se espera, es recomendable cambiar al cursor PC manualmente.

Comportamiento con NVDA

NVDA trabaja con modo exploración y modo foco. En campos de edición entrará automáticamente en modo foco. Si en algún momento la navegación no funciona bien, se puede cambiar manualmente con NVDA + Espacio.

Ejemplo práctico

Al abrir WhatsApp Desktop, el foco cae en la lista de chats. Se pulsa flecha abajo hasta escuchar el nombre de un contacto, luego Intro para abrir esa conversación y, desde ahí, Tab varias veces hasta llegar al campo de escritura. Ese recorrido básico es el que se repite constantemente durante el uso diario.

Ejercicio del módulo

  • Recorre la lista de chats con las flechas.
  • Abra un chat con Intro.
  • Explora los mensajes con las flechas.
  • Localiza el campo de escritura con Tab.
  • Vuelve a la lista de chats con Shift + Tab.

Resultado esperado

Al terminar este módulo debes ser capaz de distinguir claramente las tres zonas de la aplicación, moverse entre ellas sin perderse y abrir y cerrar conversaciones con seguridad. Si aquí se siente cómodo, el resto del curso deja de ser complicado. Si no, conviene repetir este módulo antes de avanzar, porque todo lo demás se construye sobre esto.

Módulo 4. Moverse entre chats

Cambiar de conversación parece lo más básico del mundo, y sin embargo es uno de los puntos donde más se pierde el foco con lectores de pantalla. El problema no es la acción en sí, sino no saber exactamente dónde se está en cada momento.

Saber dónde está el foco

Cuando se abre WhatsApp Desktop, normalmente el foco cae en la lista de chats, pero no siempre. A veces se queda en la conversación que estaba abierta o en algún otro elemento. Si esto no está claro, se empieza a pulsar teclas sin control.

La regla básica es sencilla: antes de moverse, hay que asegurarse de estar en la lista de chats. Para volver a ella desde cualquier punto, se pulsa Shift + Tabulador varias veces hasta que el lector empiece a leer nombres de contactos o grupos. Eso confirma que se está en el lugar correcto.

Navegación por la lista

Una vez dentro de la lista de chats, se usa flecha abajo para avanzar y flecha arriba para retroceder. El lector de pantalla irá leyendo el nombre del contacto o grupo, parte del último mensaje y el indicador de no leído si lo hay.

Abrir y cerrar un chat

Cuando se escucha el chat que se quiere abrir, se pulsa Intro y la conversación aparece en la zona central. Para volver a la lista después de abrir un chat, se usa Shift + Tabulador varias veces hasta escuchar nuevamente la lista de conversaciones. El número de pulsaciones necesarias puede variar según el punto en el que se esté.

Buscar un chat concreto

Cuando hay muchas conversaciones, moverse con flechas puede ser lento. La manera más rápida de llegar a un chat concreto es con Control + F, que abre el campo de búsqueda. Se escribe el nombre del contacto o del grupo y se pulsa Intro o se baja con flechas para seleccionar el resultado.

Ejemplo práctico

Estando leyendo un chat, se quiere cambiar a otro. Se pulsa Shift + Tabulador hasta escuchar la lista de chats, se usa flecha abajo para encontrar la siguiente conversación y se pulsa Intro para abrirla. Sin conocer este recorrido, la gente se queda «encerrada» en una conversación sin saber cómo salir.

Errores comunes

  • Pulsar Tabulador esperando cambiar de chat directamente.
  • No distinguir entre estar en la conversación o en la lista.
  • No usar Shift + Tabulador para retroceder.
  • Escribir sin darse cuenta de que el foco no está en el campo de texto.

Ejercicio del módulo

  • Abre WhatsApp Desktop.
  • Muévete por la lista de chats con las flechas.
  • Abra tres conversaciones distintas.
  • Después de cada una, vuelva a la lista con Shift + Tabulador.
  • Usa Control + F para buscar un contacto por nombre.

Resultado esperado

Al terminar este módulo debes ser capaz de saber en qué zona está en cada momento, cambiar de chat sin perderse y buscar una conversación rápidamente por nombre.

Módulo 5. Leer mensajes correctamente

Leer mensajes no es solo escuchar lo que dice el lector. Si no se sabe cómo moverse dentro de la conversación, se pierde el contexto, se saltan mensajes o no se entiende quién dijo qué. Aquí es donde el lector de pantalla marca la diferencia.

Estructura de cada mensaje

En un chat individual, cada mensaje suele incluir el contenido del texto y la hora de envío. En un grupo, también aparece el nombre del remitente antes del contenido. El lector de pantalla puede no leer todo automáticamente en orden perfecto, por lo que hay que saber moverse con consciencia.

Cómo empezar a leer una conversación

Después de abrir un chat, se usan las flechas arriba y abajo para recorrer los mensajes. Dependiendo de la versión de la aplicación, flecha abajo puede avanzar hacia mensajes más recientes o hacia los más antiguos. Conviene probar ambas para entender el comportamiento en el momento de la instalación.

Lectura continua con JAWS

JAWS permite usar lectura continua para escuchar varios mensajes seguidos sin tener que moverse manualmente. El comando es Insert + Flecha abajo. Esto resulta muy útil para ponerse al día en conversaciones con muchos mensajes.

Lectura continua con NVDA

En NVDA el comando equivalente es NVDA + Flecha abajo. Del mismo modo, permite escuchar la conversación de forma fluida sin necesidad de ir mensaje por mensaje.

Modo correcto según el lector

Con JAWS, si la navegación no responde bien, hay que asegurarse de estar en cursor PC. Con NVDA, si algo no se lee correctamente, se puede cambiar manualmente entre modo exploración y modo foco con NVDA + Espacio.

Identificar quién escribe en grupos

En los grupos, el lector de pantalla anuncia el nombre del remitente antes del contenido del mensaje. Si se mueve demasiado rápido entre mensajes, ese nombre puede pasarse por alto. La recomendación es reducir el ritmo de navegación y escuchar siempre el inicio de cada mensaje antes de avanzar al siguiente.

Leer mensajes largos

Algunos mensajes ocupan varias líneas. En ese caso puede ser necesario usar los comandos de lectura continua o moverse línea a línea dentro del mismo mensaje. El comportamiento puede variar ligeramente según la versión de la aplicación y el lector que se use.

Errores comunes

  • Leer solo el último mensaje sin revisar el contexto anterior.
  • No prestar atención a quién escribe en grupos.
  • Usar Tabulador en lugar de flechas para leer mensajes.
  • No cambiar el modo del lector cuando algo no funciona como se espera.

Ejercicio del módulo

  • Abra un chat con varios mensajes.
  • Lee la conversación completa usando las flechas.
  • Repite la lectura usando lectura continua.
  • Abre un grupo e identifique quién escribe en cada mensaje.

Resultado esperado

Al terminar este módulo debes ser capaz de leer una conversación completa sin perder el hilo, identificar a los participantes en grupos y usar la lectura continua cuando convenga. A partir de aquí ya no se está probando WhatsApp, sino usándolo con criterio.

Módulo 6. Escribir y enviar mensajes

Escribir parece trivial hasta que el foco no está donde uno cree. Este módulo trata de evitar exactamente eso.

Localizar el campo de escritura

Antes de escribir, hay que estar posicionado en el campo correcto. Desde la conversación abierta, se pulsa Tabulador varias veces hasta que el lector anuncie algo como «campo de texto», «área de escritura» o similar. Si el lector no anuncia claramente que se está en una zona editable, no se está donde se cree.

Escritura básica

Una vez dentro del campo de texto, se escribe normalmente con el teclado. No hay diferencias entre JAWS y NVDA en este punto.

Enviar un mensaje

Para enviar, se pulsa Intro. El mensaje se envía de inmediato. Este es un punto importante: Intro no baja de línea como en un procesador de texto, sino que envía el mensaje.

Insertar un salto de línea sin enviar

Si se quiere escribir un mensaje con varias líneas dentro del mismo envío, se usa Shift + Intro para añadir una nueva línea sin que el mensaje salga. Por ejemplo: se escribe «Hola», se pulsa Shift + Intro, se escribe «¿Cómo estás?» y después se pulsa Intro para enviar. El receptor recibe un único mensaje con dos líneas.

Confirmar que el mensaje se envió

Después de enviar, el lector suele anunciar el mensaje en la conversación y el foco vuelve al campo de escritura. Si eso no ocurre, lo más probable es que el foco no estuviera realmente en el campo de texto.

Formato básico en los mensajes

WhatsApp permite aplicar algo de formato al texto usando caracteres especiales:

  • Texto en negrita: rodear las palabras con asteriscos, por ejemplo *hola*.
  • Texto en cursiva: rodear con guiones bajos, por ejemplo _hola_.
  • Texto tachado: rodear con virgulillas, por ejemplo ~hola~.
  • Texto monoespaciado (código): rodear con acentos graves, por ejemplo `hola`.

Estos formatos funcionan en todas las versiones de WhatsApp, incluyendo la versión Desktop.

El lector de pantalla puede no anunciar estos formatos de forma explícita, así que conviene usarlos con moderación y revisar el mensaje antes de enviarlo.

Errores comunes

  • Escribir sin estar realmente en el campo de texto.
  • Pulsar Intro pensando que baja de línea cuando en realidad envía el mensaje.
  • Enviar mensajes incompletos por error.
  • No revisar lo escrito antes de enviar.

Ejercicio del módulo

  • Abra un chat.
  • Localiza el campo de escritura con Tabulador.
  • Escribe un mensaje corto y envíelo.
  • Escribe un mensaje en dos líneas usando Shift + Intro.
  • Envía varios mensajes seguidos y confirma que llegan correctamente.

Resultado esperado

Al terminar este módulo debes saber cuándo está escribiendo realmente, enviar mensajes sin errores y controlar los saltos de línea con precisión.

Módulo 7. Responder, reenviar y reaccionar a mensajes

Aquí empieza el uso más inteligente de WhatsApp. No se trata solo de escribir, sino de interactuar con mensajes concretos de forma precisa.

Responder a un mensaje específico

Responder a un mensaje concreto no es lo mismo que escribir en el campo de texto sin más. Al citar un mensaje, el receptor ve claramente a qué intervención se está contestando, lo que resulta especialmente útil en grupos con mucha actividad.

Para hacerlo, hay que situarse sobre el mensaje con las flechas, abrir el menú contextual con la tecla Aplicaciones o con Shift + F10, buscar la opción «Responder» y pulsar Intro. El foco se mueve al campo de escritura con el mensaje citado ya incorporado, y desde ahí se escribe la respuesta y se pulsa Intro para enviar.

Reenviar un mensaje

Reenviar sirve para enviar a otro chat un mensaje que se ha recibido o enviado, sin necesidad de copiarlo y pegarlo manualmente.

Los pasos son: situarse sobre el mensaje, abrir el menú contextual, buscar «Reenviar» y pulsar Intro. Se abrirá la lista de contactos disponibles, se selecciona el destino con las flechas y se pulsa Intro para confirmar.

Reaccionar a mensajes con emojis

Dependiendo de la versión de la aplicación, es posible reaccionar a un mensaje con un emoji. Los pasos son similares: situarse sobre el mensaje, abrir el menú contextual y buscar las opciones de reacción. Hay que tener en cuenta que esta función puede no ser completamente fluida con todos los lectores de pantalla en todas las versiones, por lo que conviene explorarla sin presión.

Ejemplo práctico

Se recibe un mensaje importante que se quiere enviar a otro contacto. En lugar de copiarlo manualmente, se abre el menú contextual con Shift + F10, se selecciona «Reenviar», se elige el destinatario y se confirma. Todo sin copiar ni pegar nada.

Errores comunes

  • No usar el menú contextual y intentar responder escribiendo sin citar.
  • No saber dónde está el foco tras abrir el menú contextual.
  • Confundirse al elegir el destinatario al reenviar.

Ejercicio del módulo

  • Responde a un mensaje concreto de una conversación.
  • Reenvía un mensaje a otro chat.
  • Explora el menú contextual de varios mensajes para conocer las opciones disponibles.

Resultado esperado

Al terminar este módulo debes ser capaz de responder a mensajes específicos, reenviar contenido sin copiar y usar el menú contextual con soltura. A partir de aquí ya se está entrando en un uso real y completo de la herramienta.

Módulo 8. Adjuntar y enviar archivos

Enviar archivos desde el ordenador es una de las grandes ventajas de usar WhatsApp Desktop frente al móvil. Desde aquí se pueden compartir documentos, imágenes y otros archivos de forma cómoda y rápida. Pero si no se sabe localizar el botón correcto o manejar el explorador de archivos, el proceso se convierte en un bloqueo.

Localizar el botón de adjuntar

Dentro de una conversación abierta, hay que pulsar Tabulador hasta encontrar el botón de adjuntar. El lector puede anunciarlo como «Adjuntar», «Agregar archivo», «Clip» o similar, según la versión. Una vez localizado, se pulsa Intro y se abrirá un menú con las distintas opciones.

Tipos de archivo que se pueden enviar

Desde WhatsApp Desktop en Windows se pueden adjuntar principalmente:

  • Documentos en cualquier formato (PDF, Word, Excel, etc.).
  • Imágenes y vídeos.
  • Contactos de la agenda.

La opción de compartir ubicación está limitada en la versión de escritorio.

Seleccionar el archivo

Después de elegir el tipo de contenido, se abre el explorador de archivos estándar de Windows. Aquí ya se está en un entorno conocido del sistema operativo. Se usan Tabulador y las flechas para navegar, se localiza la carpeta donde está el archivo y se pulsa Intro sobre él.

Confirmar el envío

Tras seleccionar el archivo, aparece una pantalla de confirmación. Hay que buscar el botón «Enviar» con Tabulador y pulsar Intro. Sin este paso, el archivo no se envía aunque ya esté seleccionado.

Enviar archivos con arrastrar y soltar

Aunque no es el método principal para usuarios de lector de pantalla, es posible arrastrar un archivo desde el Explorador de Windows directamente a la ventana de WhatsApp. Este método puede resultar útil en combinación con el ratón si en algún momento se prefiere usarlo.

Ejemplo práctico

Se quiere enviar un PDF. Se abre el chat correspondiente, se pulsa Tabulador hasta «Adjuntar», se pulsa Intro, se selecciona «Documento», se navega hasta la carpeta Descargas, se pulsa Intro sobre el PDF, se busca el botón «Enviar» y se pulsa Intro. En total, unos pocos pasos bien encadenados.

Errores comunes

  • No encontrar el botón de adjuntar por pasar por alto su nombre en el lector.
  • Perderse en el explorador de archivos sin llegar a seleccionar nada.
  • Seleccionar el archivo pero olvidar confirmar el envío.

Ejercicio del módulo

  • Envía un documento desde la carpeta Descargas.
  • Envía una imagen.
  • Comprueba que ambos aparecen correctamente en la conversación.

Resultado esperado

Al terminar este módulo debes ser capaz de abrir el menú de adjuntos, seleccionar archivos sin perderse en el explorador y confirmar el envío correctamente.

Módulo 9. Mensajes de voz

El uso de mensajes de voz en la versión de escritorio no es tan inmediato como en el móvil. Aquí es importante entender bien dónde está el control de grabación y qué estado tiene en cada momento para no enviar cosas sin querer o dejar grabaciones sin finalizar.

Comprobar los permisos del micrófono

Antes de intentar grabar por primera vez, hay que asegurarse de que Windows tiene permiso para que WhatsApp use el micrófono. Si no se ha concedido ese permiso, la grabación no funcionará y puede que el error no sea obvio.

Para verificarlo: se va a Configuración de Windows, luego a Privacidad y seguridad, y dentro de esa sección se busca la opción «Micrófono». En Windows 10, la ruta puede aparecer como Configuración, Privacidad, Micrófono. Ahí hay que asegurarse de que el acceso al micrófono está activado y que WhatsApp figura entre las aplicaciones autorizadas. La ruta puede variar ligeramente según la versión de Windows.

Localizar el botón de grabación

Dentro de un chat, hay que pulsar Tabulador hasta encontrar el botón de grabación. El lector puede anunciarlo como «Grabar mensaje de voz», «Micrófono» o «Botón de audio». El nombre puede variar según la versión.

Iniciar y detener la grabación

Se pulsa Intro sobre el botón para iniciar la grabación. En ese momento comienza a capturar el audio. Algunas versiones cambian el botón a «Detener» o muestran un control distinto al iniciar. Para detener, se pulsa Intro nuevamente sobre ese botón o se busca con Tabulador el botón de detener si aparece en una posición diferente. Es importante confirmar que la grabación se ha detenido antes de continuar.

Enviar el audio

Después de grabar y detener, hay que buscar el botón «Enviar» con Tabulador y pulsar Intro. Si no se hace este paso, el audio no se envía aunque ya esté grabado.

Cancelar una grabación

Si se empieza a grabar por error, en la mayoría de las versiones hay un botón de cancelar o eliminar que aparece junto al de enviar. Se puede buscar con Tabulador antes de confirmar el envío.

Reproducir audios recibidos

Para escuchar un mensaje de voz, hay que situarse sobre él con las flechas y pulsar Intro en el botón de reproducir. El lector puede anunciar la duración del audio o el estado de reproducción.

Errores comunes

  • No saber si se está grabando o no porque el lector no lo anuncia con claridad.
  • No detener la grabación antes de buscar el botón de enviar.
  • Grabar el audio correctamente pero olvidar confirmar el envío.
  • No haber concedido permisos de micrófono a la aplicación.

Ejercicio del módulo

  • Comprueba que los permisos de micrófono están activados.
  • Localiza el botón de grabación en un chat.
  • Graba un mensaje de voz corto.
  • Detenlo correctamente y envíalo.
  • Escucha un audio recibido en esa misma conversación.

Resultado esperado

Al terminar este módulo debes ser capaz de controlar el inicio y el fin de la grabación, enviar audios correctamente y resolver posibles problemas de permisos de micrófono.

Módulo 10. Gestión de chats

Aquí ya no se trata solo de usar WhatsApp, sino de mantenerlo ordenado. Si no se hace una gestión mínima de las conversaciones, en pocas semanas se tiene un caos imposible de manejar.

Opciones principales de gestión

Las acciones disponibles sobre un chat son:

  • Archivar: oculta el chat de la lista principal sin eliminarlo. Se puede recuperar en cualquier momento.
  • Eliminar: borra la conversación completa. No es reversible desde la aplicación.
  • Fijar: coloca el chat en la parte superior de la lista, independientemente de cuándo llegue el siguiente mensaje.
  • Marcar como no leído: señala el chat como pendiente aunque ya se haya abierto.
  • Silenciar notificaciones: desactiva los avisos de ese chat sin archivarlo.

Acceder al menú de gestión

Para acceder a estas opciones, hay que situarse sobre el chat en la lista de conversaciones y abrir el menú contextual con la tecla Aplicaciones o con Shift + F10. Desde ahí se navega con las flechas y se pulsa Intro sobre la opción deseada.

Diferencia entre archivar y eliminar

Este es el punto donde más se cometen errores. Archivar oculta el chat pero no lo borra, y se puede recuperar accediendo a la sección de chats archivados. Eliminar borra todo el historial de la conversación de forma permanente. Ante la duda, siempre es mejor archivar.

Recuperar chats archivados

Para ver los chats archivados, hay que ir a la parte inferior de la lista de conversaciones, donde aparece la opción «Archivados». Al entrar, se pueden ver todas las conversaciones guardadas y restaurarlas a la lista principal si se quiere.

Fijar conversaciones importantes

Se puede fijar hasta un número limitado de chats en la parte superior de la lista. Esto resulta muy útil para tener siempre a mano a los contactos o grupos con los que se habla más frecuentemente.

Ejemplo práctico

Hay un grupo muy activo que genera demasiadas notificaciones pero que no se quiere perder. La solución es archivarlo temporalmente: desaparece de la vista principal pero no se pierde nada. Cuando se quiera volver a él, se recupera desde chats archivados.

Errores comunes

  • Eliminar un chat cuando se quería solo archivarlo.
  • No saber cómo recuperar chats archivados.
  • No usar el fijado para los contactos más importantes.
  • Dejar la lista de chats sin organizar hasta que se vuelve inmanejable.

Ejercicio del módulo

  • Archiva un chat.
  • Fija otro chat en la parte superior de la lista.
  • Marca un chat como no leído.
  • Elimina un chat de prueba creado para este ejercicio.
  • Accede a chats archivados y recupere el que archivó.

Resultado esperado

Al terminar este módulo debes ser capaz de organizar la lista de chats, distinguir claramente entre archivar y eliminar, y mantener un entorno limpio y manejable.

Módulo 12. Notificaciones en Windows

Las notificaciones no dependen solo de WhatsApp. También dependen de cómo Windows gestiona esos avisos, y es importante entender esa relación para no atribuirle a la aplicación fallos que en realidad son del sistema.

Tipos de notificación

Cuando llega un mensaje nuevo, pueden producirse distintos tipos de aviso de forma combinada o por separado:

  • Sonido de aviso.
  • Banner emergente en la esquina de la pantalla.
  • Registro en el centro de notificaciones de Windows.

Comportamiento con lectores de pantalla

JAWS y NVDA suelen anunciar las notificaciones emergentes cuando llegan. Sin embargo, si llegan varias seguidas en poco tiempo, puede que no se lean todas de manera completa. En esos casos, es útil revisar el centro de notificaciones de Windows manualmente.

Centro de notificaciones de Windows

Se accede pulsando Windows + N. Dentro del panel, se usa Tabulador para moverse entre elementos y las flechas para navegar por la lista de notificaciones. Al pulsar Intro sobre una notificación de WhatsApp, se abre el chat correspondiente. Hay que tener en cuenta que en algunas ocasiones el foco puede no devolverse correctamente a la aplicación, en cuyo caso hay que volver manualmente a WhatsApp y buscar el chat.

Configuración de notificaciones en Windows

Si las notificaciones no aparecen o se comportan de forma inesperada, el primer sitio donde revisar es la configuración del sistema. La ruta es: Configuración de Windows, luego Sistema, luego Notificaciones. Desde ahí se puede activar o desactivar WhatsApp como fuente de notificaciones y elegir el tipo de aviso que se quiere recibir.

Modo de concentración o No molestar

Windows incluye un modo llamado «No molestar» o «Modo de concentración» que puede silenciar todas las notificaciones de aplicaciones. Si de repente dejan de llegar avisos, conviene comprobar que ese modo no esté activado.

Errores comunes

  • Pensar que WhatsApp falla cuando en realidad las notificaciones están desactivadas en Windows.
  • No revisar la configuración del sistema cuando los avisos no llegan.
  • No conocer el acceso al centro de notificaciones con Windows + N.

Ejercicio del módulo

  • Abre el centro de notificaciones con Windows + N.
  • Accede a la notificación del mensaje.
  • Comprueba si el foco vuelve correctamente al chat.
  • Revisa la configuración de notificaciones de Windows.

Resultado esperado

Al terminar este módulo debes entender cómo llegan las notificaciones, saber abrirlas desde el centro de notificaciones y ser capaz de resolver los fallos más comunes relacionados con los avisos.

Módulo 13. Uso de grupos

Un grupo no es un chat más. Es varias conversaciones mezcladas al mismo tiempo. Si no se sabe leerlo bien, se pierde quién dice qué y se acaba ignorando el grupo por saturación.

Qué cambia respecto a un chat individual

En un grupo hay múltiples participantes activos, cada mensaje tiene un remitente distinto y el ritmo de actividad puede ser mucho más elevado que en un chat individual. Todo esto exige más atención al navegar y leer.

Identificar quién escribe

Cuando se recorren los mensajes con las flechas, el lector de pantalla anuncia el nombre del remitente antes del contenido. Si se mueve demasiado rápido entre mensajes, ese dato se puede perder fácilmente. La recomendación es reducir la velocidad de navegación y escuchar siempre el inicio de cada mensaje antes de avanzar al siguiente.

Lectura en grupos muy activos

En grupos con mucha actividad, la lectura continua puede mezclar intervenciones de distintas personas de un modo confuso. En esos casos, es preferible ir mensaje por mensaje con las flechas para mantener el contexto claro.

Responder en un grupo

Al igual que en los chats individuales, hay dos opciones: responder de forma general escribiendo en el campo de texto, o responder a un mensaje concreto para que quede claro el contexto. Para hacer esto último, hay que situarse sobre el mensaje, abrir el menú contextual con Shift + F10, seleccionar «Responder» y escribir la respuesta. Esto mantiene la claridad de la conversación para todos los participantes.

Silenciar grupos

Si un grupo genera demasiadas notificaciones o interrupciones, se puede silenciar desde las opciones del propio chat. Hay que abrir la información del grupo o acceder al menú contextual sobre su nombre en la lista de chats, y buscar la opción «Silenciar notificaciones». Se puede elegir silenciarlo por un tiempo determinado o de forma indefinida.

Ver y gestionar miembros del grupo

Accediendo a la información del grupo, que normalmente se puede abrir con Tabulador desde la parte superior del chat, se puede ver la lista de participantes, saber quién es administrador y, si se tiene ese rol, gestionar quién puede formar parte del grupo.

Ejemplo práctico

En un grupo de trabajo muy activo se quiere responder a un mensaje concreto de un compañero. Se localiza ese mensaje con las flechas, se abre el menú contextual con Shift + F10, se selecciona «Responder», se escribe el texto y se envía. El resto de los participantes verá con claridad a qué mensaje corresponde la respuesta.

Errores comunes

  • Leer los mensajes sin prestar atención a quién los escribe.
  • Responder sin citar, generando confusión sobre a qué mensaje va dirigida la respuesta.
  • No silenciar grupos muy activos que interrumpen constantemente.
  • Intentar seguir toda la actividad en tiempo real en grupos grandes.

Ejercicio del módulo

Realiza lo siguiente en un grupo:

  • Lee varios mensajes identificando a quién pertenece cada uno.
  • Responde a un mensaje concreto usando el menú contextual.
  • Siléncialo temporalmente y compruebe que dejan de llegar notificaciones.

Resultado esperado

Al terminar este módulo debes ser capaz de seguir conversaciones en grupo, identificar quién participa en cada momento y responder sin generar confusión.

Módulo 14. Búsqueda avanzada

La búsqueda puede ahorrar mucho tiempo cuando se necesita encontrar un mensaje o un chat concreto, pero no siempre se comporta de forma perfecta. Saber qué esperar de ella evita frustraciones.

Búsqueda global de chats

El atajo Control + F abre el campo de búsqueda general de la aplicación. Se escribe el nombre de un contacto, un grupo o cualquier término y se usan las flechas para recorrer los resultados. Al pulsar Intro sobre un resultado, se abre el chat correspondiente.

Lo que la búsqueda puede y no puede hacer

La búsqueda global lleva directamente al chat que contiene el término buscado, pero no siempre posiciona el foco en el mensaje exacto donde aparece ese texto. En muchos casos hay que recorrer manualmente la conversación con las flechas hasta encontrar el contenido específico.

Búsqueda dentro de un chat

Algunas versiones permiten buscar dentro del chat activo. Para ello, desde la conversación abierta, se accede al menú del chat o a la información del mismo, y se busca la opción de búsqueda interna. Se introduce el término y se navega entre los resultados. Esta función es más precisa que la búsqueda global para localizar un mensaje concreto dentro de una conversación larga.

Limitaciones reales de la búsqueda

La búsqueda no distingue variaciones de palabras, por lo que buscar «llegamos» no encontrará mensajes que digan «llegué». Tampoco interpreta contexto ni sinónimos: solo busca coincidencias exactas. Si se usan términos demasiado genéricos, los resultados pueden ser muy numerosos y difíciles de filtrar.

Ejemplo práctico

Se quiere encontrar un mensaje donde alguien compartió una dirección hace semanas. Se pulsa Control + F, se escribe el nombre del contacto o parte de la dirección, se abre el chat y se navega entre los mensajes hasta localizar el que se necesita. No hay atajos perfectos para llegar directamente al mensaje exacto, pero la búsqueda reduce considerablemente el trabajo.

Errores comunes

  • Esperar que la búsqueda lleve directamente al mensaje exacto en todos los casos.
  • No revisar el chat manualmente después de abrirlo desde los resultados.
  • Usar términos demasiado genéricos que devuelven demasiados resultados.

Ejercicio del módulo

Realiza lo siguiente:

  • Usa Control + F para buscar un mensaje antiguo por algún término que recuerde.
  • Abre el chat desde los resultados.
  • Localiza manualmente el mensaje dentro de la conversación.
  • Si la versión lo permite, prueba la búsqueda interna dentro del chat.

Resultado esperado

Al terminar este módulo debes ser capaz de usar la búsqueda con criterio, entender sus limitaciones y encontrar información sin frustrarse cuando los resultados no son perfectamente precisos.

Módulo 15. Accesibilidad y trucos prácticos

Aquí es donde se deja de depender de la aplicación tal como viene y se empieza a adaptarla al uso personal. Pequeños ajustes que marcan una diferencia enorme en el día a día.

Control del foco

El problema más habitual para usuarios de lector de pantalla en WhatsApp Desktop es no saber dónde está el foco del teclado en un momento dado. La solución no está en adivinar, sino en desarrollar el hábito de escuchar lo que anuncia el lector antes de actuar, usar Tabulador y Shift + Tabulador de forma consciente y no pulsar teclas al azar cuando algo no responde como se espera.

Modos en JAWS

En WhatsApp Desktop, JAWS funciona mejor en cursor PC que en cursor virtual. Si en algún momento la aplicación deja de responder correctamente, lo primero que hay que probar es cambiar al cursor PC manualmente. La aplicación está basada en tecnología web interna y el cursor virtual puede interpretar algunos elementos de forma incorrecta.

Modos en NVDA

Con NVDA, el modo que mejor funciona en esta aplicación es el modo foco, que se activa automáticamente en campos de edición. Si en algún momento la navegación se comporta de manera extraña, se puede alternar manualmente entre modo exploración y modo foco con NVDA + Espacio.

Ajuste de velocidad de voz

En conversaciones largas o grupos muy activos, reducir la velocidad de voz del lector ayuda a captar mejor el contexto. Para revisar mensajes rápidamente sin leerlos todos, aumentarla puede ser más eficiente. Dominar ese ajuste en tiempo real, sin interrumpir el flujo de trabajo, es una destreza que marca la diferencia a medida que se gana experiencia.

Reducir la saturación informativa

Mantener la lista de chats limpia es fundamental para no sentirse abrumado. Silenciar los grupos con mucha actividad que no requieren atención inmediata, archivar las conversaciones menos relevantes y usar el fijado para los contactos más importantes son hábitos que mejoran mucho la experiencia de uso.

Uso eficiente del teclado

Usar WhatsApp Desktop exclusivamente con el teclado no solo es posible, sino más eficiente que depender del ratón. Los atajos más importantes son Control + F para buscar, Shift + F10 para el menú contextual, Windows + N para el centro de notificaciones y Shift + Tabulador para volver a la lista de chats. Conocerlos bien hace que el flujo de trabajo sea fluido y sin interrupciones.

Personalización del lector de pantalla para esta aplicación

Tanto JAWS como NVDA permiten crear configuraciones específicas por aplicación. Si se usa WhatsApp Desktop con frecuencia, puede ser útil dedicar un tiempo a ajustar la velocidad, el tono o el nivel de detalle con el que el lector anuncia los elementos, de modo que la experiencia sea lo más cómoda posible.

Ejemplo práctico

Se tienen varios grupos activos que interrumpen constantemente. Se silencian los grupos, se archivan las conversaciones menos relevantes y se fijan los dos o tres contactos más importantes. El resultado es un entorno limpio, organizado y sin ruido innecesario.

Errores comunes

  • No prestar atención a lo que anuncia el lector antes de actuar.
  • No ajustar la velocidad de voz según la situación.
  • No aprovechar los atajos de teclado disponibles.
  • Intentar usar el ratón cuando el teclado resuelve todo de forma más eficiente.

Ejercicio del módulo

Realiza los siguientes ajustes:

  • Ajusta la velocidad del lector a su ritmo habitual de lectura.
  • Alterna entre modos en NVDA o JAWS y observe cómo cambia el comportamiento.
  • Organiza tu lista de chats: archive los irrelevantes, fije los importantes y silencie los grupos más activos.

Resultado esperado

Al terminar este módulo debes ser capaz de controlar el entorno de uso, adaptar la herramienta a sus necesidades y reducir los errores provocados por desorientación dentro de la aplicación.

Módulo 16. Problemas comunes y soluciones

WhatsApp Desktop funciona bien... hasta que deja de hacerlo. Y casi siempre el problema no es la aplicación en sí, sino pequeños detalles que se pasan por alto y tienen solución rápida.

La aplicación no conecta o los mensajes no se sincronizan

Síntomas: la aplicación muestra que no está conectada o los mensajes no aparecen aunque el móvil los recibe con normalidad.

Posibles causas: el ordenador no tiene conexión a Internet, el móvil ha perdido la vinculación o la sesión ha caducado por inactividad.

Solución: primero hay que comprobar la conexión a Internet del ordenador. Si hay conexión, se cierra WhatsApp Desktop y se vuelve a abrir. Si el problema persiste, hay que desvincularlo y repetir el proceso del Módulo 2: vincular el dispositivo escaneando un nuevo código QR.

El lector de pantalla no lee correctamente

Síntomas: hay elementos que no se anuncian, el foco parece «perdido» o la navegación no responde de forma lógica.

Posibles causas: se está usando el modo incorrecto del lector, o ha habido un problema puntual de la aplicación.

Solución: con JAWS, cambiar entre cursor virtual y cursor PC. Con NVDA, alternar el modo con NVDA + Espacio. En ambos casos, mover el foco con Tabulador y Shift + Tabulador hasta recuperar el contexto. A veces no es que no funcione, es que se está en el modo equivocado.

Los mensajes no se envían

Síntomas: se escribe pero el mensaje no llega al destinatario.

Posibles causas: el foco no está realmente en el campo de escritura, o hay problemas de conexión.

Solución: asegurarse de estar posicionado en el campo de texto comprobando que el lector anuncia una zona editable. Pulsar Intro para enviar. Verificar la conexión a Internet. Enviar mensajes «al vacío» por estar en el elemento equivocado es más habitual de lo que parece.

No llegan notificaciones

Síntomas: se reciben mensajes en el móvil pero no hay ningún aviso en el ordenador.

Posibles causas: las notificaciones están desactivadas dentro de WhatsApp, o están bloqueadas en la configuración de Windows.

Solución: revisar primero la configuración de notificaciones dentro de WhatsApp Desktop. Si ahí está todo correcto, revisar la configuración de Windows en Sistema, Notificaciones. El fallo suele estar en el sistema, no en la aplicación.

No se encuentra un chat

Síntomas: se sabe que existe una conversación pero no aparece en la lista.

Posibles causas: el chat está archivado, o el nombre del contacto no coincide con lo que se recuerda.

Solución: usar Control + F para buscar por cualquier término relacionado. Si no aparece en la búsqueda general, revisar la sección de chats archivados. Nada se pierde, pero sí puede estar escondido.

La aplicación se cierra sola o no responde

Síntomas: WhatsApp Desktop se cierra inesperadamente o se queda sin responder.

Posibles causas: un problema puntual de la aplicación, una actualización pendiente o un conflicto con otros programas.

Solución: cerrar la aplicación completamente y volver a abrirla. Si ocurre con frecuencia, conviene comprobar si hay actualizaciones disponibles en la Microsoft Store o en la web oficial, y en ese caso instalarlas.

Ejemplo práctico

No llegan notificaciones aunque sí se reciben mensajes en el móvil. Se abre el centro de notificaciones con Windows + N y no aparece nada. Se revisa la configuración del sistema y se descubre que las notificaciones de WhatsApp están desactivadas en Windows. Se activan y el problema se resuelve sin necesidad de tocar nada dentro de la aplicación.

Errores comunes

  • Atribuir todos los problemas a la aplicación sin revisar primero el sistema.
  • No comprobar la conexión a Internet como primer paso ante cualquier fallo.
  • No revisar el estado del foco cuando algo no responde.
  • No repetir el proceso de vinculación cuando la sesión ha caducado.

Ejercicio del módulo

Practica lo siguiente:

  • Simula una pérdida de foco cerrando y reabriendo la aplicación, y recupérelo.
  • Busca un chat archivado y recupérelo en la lista principal.
  • Revisa la configuración de notificaciones tanto en WhatsApp como en Windows.

Resultado esperado

Al terminar este módulo debes ser capaz de identificar los problemas más habituales, aplicar las soluciones básicas por su cuenta y no depender de ayuda externa para resolver errores simples.

Módulo 17. Práctica completa y cierre del curso

Aquí no hay teoría nueva. Este módulo sirve para demostrar si todo lo anterior está realmente integrado. Si se han seguido los módulos y se han hecho los ejercicios, esta práctica debería salir con naturalidad. Si no, es el momento de identificar qué partes necesitan repaso.

Escenario práctico completo

Realiza la siguiente secuencia completa sin consultar los módulos anteriores:

  • Abre WhatsApp Desktop.
  • Localiza la lista de chats y oriéntese dentro de ella.
  • Usa Control + F para buscar un contacto concreto.
  • Abre esa conversación.
  • Lee los últimos mensajes e identifique quién escribe si es un grupo.
  • Escribe un mensaje en dos líneas usando Shift + Intro y envíelo.
  • Responde a un mensaje concreto usando el menú contextual.
  • Adjunta un archivo desde el ordenador y envíelo.
  • Graba y envía un mensaje de voz.
  • Vuelve a la lista de chats y archive esa conversación.
  • Abre el centro de notificaciones con Windows + N y acceda a un mensaje desde ahí.

¿Qué se evalúa en esta práctica?

Esta secuencia pone a prueba varias competencias al mismo tiempo:

  • Control del foco: saber siempre dónde se está y cómo volver a donde se necesita estar.
  • Uso del teclado: realizar todas las acciones sin depender del ratón.
  • Comprensión de la interfaz: moverse entre zonas con seguridad.
  • Uso de funciones principales: mensajes de texto, voz, adjuntos, respuestas y búsqueda.
  • Capacidad de recuperación: resolver pequeños imprevistos sin perder el hilo.

Cierre del curso

Quien llegue a este punto habiendo hecho los ejercicios no está aprendiendo a usar WhatsApp. Ya lo está usando.

Lo que cambia con la práctica no es la herramienta: cambia la forma de trabajar con ella. La comodidad, la rapidez y la seguridad no vienen de memorizar pasos, sino de haberlos repetido hasta que se vuelven automáticos.

Si algún módulo concreto generó dificultades, ese es el que merece un repaso. No hay que llegar al final del curso sabiendo todo de memoria: hay que llegar siendo capaz de usarlo sin ayuda cuando hay que hacerlo de verdad.

Resultado esperado

Al completar este módulo debes ser capaz de usar WhatsApp Desktop de forma autónoma, moverse con seguridad por la aplicación, resolver las situaciones habituales que puedan surgir y mantener conversaciones completas desde el ordenador sin dificultades.

Resumen de atajos de teclado más usados

A continuación se recogen los atajos de teclado más útiles para el manejo de WhatsApp Desktop con lectores de pantalla:

  • Control + F: abrir la búsqueda de chats.
  • Shift + F10 o tecla Aplicaciones: abrir el menú contextual sobre el elemento seleccionado.
  • Intro: abrir un chat, activar un botón o enviar un mensaje.
  • Tabulador: avanzar entre zonas y elementos interactivos.
  • Shift + Tabulador: retroceder entre zonas y elementos.
  • Flechas arriba y abajo: navegar por la lista de chats o entre mensajes.
  • Shift + Intro: insertar un salto de línea sin enviar el mensaje.
  • Windows + N: abrir el centro de notificaciones de Windows.
  • Insert + Flecha abajo (JAWS): lectura continua.
  • NVDA + Flecha abajo: lectura continua.
  • NVDA + Espacio: alternar entre modo exploración y modo foco.
