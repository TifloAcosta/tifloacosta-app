Introducción

En este vídeo, Tony Acosta explica distintas formas de leer códigos QR y códigos de barras utilizando un iPhone con VoiceOver.

Primero muestra cómo utilizar la propia cámara del iPhone para detectar un código QR que tenemos delante. Después plantea un problema diferente: qué ocurre cuando el código está dentro del propio teléfono, por ejemplo en una fotografía o en una captura que alguien nos ha enviado.

Para resolver ese segundo caso presenta un atajo llamado «leer código», preparado para analizar imágenes que contienen códigos QR o códigos de barras y actuar según la información encontrada.

La intención es poder averiguar qué contiene un código sin necesitar otro teléfono para escanear la pantalla y, en el caso de los códigos de barras, intentar identificar mediante Internet el producto al que pertenecen.

Preparar la cámara del iPhone para leer códigos QR

Antes de comenzar, Tony comprueba que el reconocimiento de códigos QR está activado en el iPhone.

Entra en Ajustes, abre el apartado Cámara y busca la opción «Escanear códigos QR».

El conmutador debe estar activado. Tony advierte de que, si esta opción está desactivada, la cámara no podrá detectar el código aunque se intente enfocarlo correctamente.

Leer un código QR que tenemos delante

Con esa opción activada, Tony abre la aplicación Cámara y apunta el iPhone hacia un código QR.

La cámara lo detecta rápidamente.

Una vez localizado, ya es posible acceder al contenido asociado al código.

Terminada la demostración, Tony cierra la aplicación Cámara y comenta que lo hace para evitar mantenerla funcionando y consumir batería innecesariamente.

¿Qué pasa si el código QR está dentro del propio iPhone?

Aquí aparece el problema que da origen al atajo.

Puede ocurrir que alguien nos envíe una fotografía o una captura que contiene un código QR. En ese caso no resulta práctico utilizar la cámara del mismo iPhone para escanear algo que ya está en su pantalla.

Para resolverlo, Tony ha preparado un atajo denominado «leer código».

El atajo puede recibir una imagen, analizarla y extraer el contenido del código que encuentre.

Leer un código QR guardado en Fotos

Tony abre la aplicación Fotos y entra en una imagen que contiene un código QR.

Activa Compartir y, dentro de la hoja de compartir, busca el atajo «leer código».

Al activarlo, el atajo analiza la imagen.

En esta primera prueba encuentra una dirección de Internet correspondiente a una aplicación de la App Store.

El contenido detectado se muestra antes de continuar y, una vez aceptado, el enlace se abre y el iPhone muestra la correspondiente ficha en la App Store.

De esta forma es posible recibir un código QR dentro del propio teléfono y averiguar adónde conduce sin recurrir a un segundo dispositivo.

Qué hace el atajo con la información encontrada

El comportamiento depende del tipo de contenido que haya dentro del código.

Si el código contiene una dirección de Internet, el atajo permite acceder a ese enlace.

Si el resultado no es una dirección web, como puede ocurrir con la numeración obtenida de un código de barras, utiliza ese contenido para realizar una búsqueda en Internet.

Esto permite emplear el mismo atajo tanto con códigos QR como con códigos de barras.

Primera prueba con un código de barras

Tony realiza una prueba con el código de barras de un producto.

Abre Cámara y fotografía el código.

Después entra en Fotos, localiza la imagen, activa Compartir y ejecuta nuevamente el atajo «leer código».

En este caso, el contenido obtenido no es una dirección web sino la numeración del código de barras.

El atajo utiliza esa numeración para efectuar una búsqueda en Internet.

Los resultados permiten identificar el producto como un suero fisiológico monodosis de Aposán, en formato de 5 ml.

La demostración sirve para comprobar que el atajo no se limita a leer la numeración: intenta utilizarla para encontrar información que permita saber qué producto tenemos delante.

Segunda prueba: el código de barras de un libro

Tony realiza otra prueba con un código de barras relacionado con un libro.

La primera fotografía no permite obtener correctamente el código. Aprovecha el fallo para mostrar algo importante: si el código no queda suficientemente bien captado por la cámara, el atajo puede no encontrar nada.

En ese caso hay que volver a realizar la fotografía intentando encuadrar mejor el código.

Tony repite la captura, abre la nueva fotografía desde Fotos, activa Compartir y ejecuta otra vez «leer código».

Esta vez el código se reconoce y se realiza la búsqueda correspondiente.

Entre los resultados aparece el libro «La vida vista desde donde estoy».

Tony aprovecha, naturalmente, para recomendarlo.

Qué necesitas para utilizar «leer código»

El atajo utiliza acciones que no vienen incluidas de forma nativa en Atajos, por lo que necesita una aplicación complementaria llamada Actions.

Actions es gratuita.

Descargar Actions desde la App Store

Después de instalarla, conviene abrir Actions al menos una vez para que sus acciones queden disponibles para la aplicación Atajos.

Solo si posteriormente esas acciones no aparecen en Atajos es recomendable reiniciar el iPhone.

No es necesario reiniciar el dispositivo obligatoriamente cada vez que se instala la aplicación.

Una vez preparada Actions, se puede instalar el atajo: Instalar «leer código»

Una herramienta para dejar que el iPhone investigue

La utilidad del atajo está precisamente en evitar tener que saber de antemano qué clase de código estamos intentando analizar.

Puede recibir una imagen que contenga un QR, extraer su dirección y abrirla, o encontrarse con la numeración de un código de barras y utilizar Internet para intentar descubrir qué hay detrás.

También resulta especialmente práctico cuando el código se encuentra en una fotografía o captura guardada en el propio iPhone, una situación en la que utilizar directamente la cámara para escanearlo no resulta viable.

Si aparece algún problema

Tony indica que, si durante la instalación o utilización del atajo surge alguna dificultad, se le puede consultar mediante WhatsApp en el número +34 603 51 63 98.

La idea es poder comentar el problema concreto e intentar encontrar una solución.

Despedida

Tony espera que tanto el atajo como la explicación resulten útiles y permitan sacar un poco más de partido al iPhone para acceder a códigos QR y códigos de barras con mayor autonomía.

Invita a dejar comentarios sobre la experiencia y se despide hasta la siguiente entrega, deseando un feliz verano.
