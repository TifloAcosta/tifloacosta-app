# Android 1.1.0 lector limpio y Compartir Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Partir de la `main` que ya contiene las correcciones 1.0.4, integrar de forma selectiva la función Compartir con TifloAcosta y convertir la lectura limpia en un servicio común de Actualidad, Buscar y Compartir, entregando una candidata Android 1.1.0 (`versionCode 6`).

**Architecture:** La rama de integración nace de `main`; no se fusiona a ciegas `feature/compartir-con-tifloacosta`. Se portan primero los componentes nuevos y probados de recepción, clasificación, obtención y limpieza, y después se integran manualmente los archivos que también cambiaron en `main` (`app.mjs`, Buscar, Actualidad, vídeos y configuración Android). `readable-page` permanece puro; `readable-loader` reclasifica redirecciones; `reader-session` mantiene historial y guardas de peticiones; la pantalla `reader` sirve a Actualidad y Buscar, mientras Compartir conserva su sesión efímera y reutiliza los mismos componentes.

**Tech Stack:** Android Java, Capacitor 8.5.2, JavaScript ESM, Node.js 22 `node:test`, Gradle/Android SDK, YouTube IFrame API existente.

**Spec:** `docs/superpowers/specs/2026-09-22-android-lector-limpio-integrado-design.md`

## Global Constraints

- La base de integración es `main` en `9cfdc72808cd85c71e83957c34b52827c674b838` o un descendiente posterior verificado antes de empezar.
- La candidata final usa `versionName "1.1.0"` y `versionCode 6`.
- El AAB 1.0.4 (`versionCode 5`) ya subido al borrador de Play Console no se confirma ni se publica.
- Un solo motor de lectura limpia para Actualidad, Buscar y Compartir.
- `TifloWebFetchPlugin`: solo HTTP/HTTPS, máximo 5 redirecciones, 15 segundos totales, 5 MiB, y tipos `text/html`, `application/xhtml+xml`, `text/plain`.
- El HTML remoto nunca se inserta con `innerHTML`, no ejecuta JavaScript remoto y no reutiliza cookies o sesiones del navegador.
- Clasificación determinista: YouTube → reproductor; descarga conocida → Descargas; web → lector limpio; texto puro compartido → Buscar precargado sin ejecución automática.
- Actualidad abre lectura limpia como acción principal; `Abrir fuente original` queda como alternativa secundaria y recuperación.
- Buscar abre exactamente el elemento seleccionado y no reduce resultados a una sección genérica.
- Los enlaces útiles dentro del lector vuelven al clasificador común.
- Compartir conserva sesión efímera y `moveTaskToBack(true)` al finalizar.
- No hay autoplay ni descargas automáticas.
- La interfaz permanece en español e inglés.
- Las pruebas manuales no se limitan a TalkBack; se validará con el lector de pantalla que utilicen los probadores.
- No portar cambios no relacionados de PR #66: paleta visual, PWA, sincronización editorial, catálogos web o cualquier otra mejora ajena a esta especificación.
- No fusionar a `main` ni publicar en Google Play hasta completar pruebas y recibir visto bueno final.

## Review Focus

- URL corta que termina en YouTube o descarga: debe reclasificarse tras la redirección y no mostrarse como artículo.
- Dos aperturas casi simultáneas: la respuesta de una solicitud antigua no puede sustituir la navegación más reciente.
- Página índice con poco texto pero enlaces editoriales descriptivos: debe seguir siendo una lectura fiable y navegable.
- Resultado de Buscar de tipo desconocido: debe quedarse en Buscar sin navegar silenciosamente a un destino incorrecto.
- Volver desde `Página 3 → Página 2 → Página 1 → origen`: debe respetar primero historial del lector y después restaurar origen/foco.
