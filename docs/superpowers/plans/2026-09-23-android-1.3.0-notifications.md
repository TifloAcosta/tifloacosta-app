# Android 1.3.0 Notifications Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Finish native Android notifications so permission is user-initiated from Settings, OneSignal is genuinely connected, and notification taps open safe TifloAcosta destinations.

**Architecture:** Keep `createNotificationService` as the UI-facing abstraction, add an app-owned OneSignal adapter behind it, normalize notification payloads in a pure module, and queue clicks until router/content startup is ready. Route valid destinations into existing app functions rather than duplicating reader, video, resource, or download logic.

**Tech Stack:** Capacitor 8.5.2, `@onesignal/capacitor-plugin` 1.1.6, JavaScript ES modules, Node 22 test runner, Android/Gradle, OneSignal App ID `ed030723-7f6f-4745-8cd3-6938a9d04377`.

**Spec:** `docs/superpowers/specs/2026-09-23-android-1.3.0-design.md`

## Global Constraints

- Do not request notification permission automatically at startup.
- The user must trigger permission from Settings > Notifications > Activate notifications.
- Reuse the existing OneSignal application; do not create another OneSignal project.
- Keep Android subscriptions distinguishable from existing Web Push subscriptions.
- Do not modify root `notifications.js` except if a later review proves a compatibility defect; web behavior is outside this plan.
- `@onesignal/capacitor-plugin` remains pinned to `1.1.6`.
- Keep `ONESIGNAL_DISABLE_LOCATION=true` in Android sync/build workflows.
- Invalid, missing, stale, or unsafe notification destinations fall back to Home.
- Do not make accessibility behavior TalkBack-specific.
- Physical-device delivery validation is explicitly deferred because Tony does not currently have an Android device.
- Do not claim end-to-end hardware validation until that deferred test is actually performed.

## Review Focus

- A malformed `additionalData` value (`null`, array, scalar, unexpected nested values) must fall back to Home without throwing.
- Unsafe URL schemes (`javascript:`, `file:`, `intent:`) must never be opened.
- A OneSignal initialization failure must leave the rest of TifloAcosta usable and expose notifications as unavailable.
- Multiple notification clicks before startup readiness must result in one navigation, using the most recent pending destination.
- Returning from Android notification settings must let Settings refresh the current permission state without forcing focus.

Create `mobile/src/core/notification-destination.mjs`:

```js
import { youtubeVideoId } from './share-classifier.mjs';

const TYPES = new Set(['general', 'news', 'video', 'resource', 'download']);

function text(value, max = 200) {
  return typeof value === 'string' ? value.trim().slice(0, max) : '';
}

function safeHttpUrl(value) {
  const raw = text(value, 2048);
  if (!raw) return '';
  try {
    const url = new URL(raw);
    return url.protocol === 'http:' || url.protocol === 'https:' ? url.href : '';
  } catch {
    return '';
  }
}

function validYoutubeId(value) {
  const id = text(value, 32);
  return /^[A-Za-z0-9_-]{11}$/.test(id) ? id : '';
}

export function normalizeNotificationDestination(value) {
  if (!value || typeof value !== 'object' || Array.isArray(value)) return { type: 'general' };
  const type = text(value.tiflo_type, 32).toLowerCase();
  if (!TYPES.has(type) || type === 'general') return { type: 'general' };

  const url = safeHttpUrl(value.tiflo_url);
  const title = text(value.tiflo_title, 200);
  const rawId = text(value.tiflo_id, 200);

  if (type === 'video') {
    const id = validYoutubeId(rawId) || youtubeVideoId(url);
    return id ? { type, id, url, title } : { type: 'general' };
  }

  if (!url) return { type: 'general' };
  if (type === 'resource') return { type, id: rawId, url, title };
  return { type, url, title };
}
```

Create `mobile/src/native/onesignal-notifications.mjs`. The implementation must:

```js
import { normalizeNotificationDestination } from '../core/notification-destination.mjs';

export function createOneSignalNotifications({ sdk, appId, onDestination = () => {} }) {
  let started = false;
  let failed = false;

  async function state() {
    if (!started || failed) return 'unavailable';
    if (await sdk.Notifications.hasPermission()) return 'authorized';
    return (await sdk.Notifications.canRequestPermission()) ? 'not-requested' : 'denied';
  }

  async function start() {
    try {
      await sdk.initialize(appId);
      sdk.Notifications.addEventListener('click', event => {
        onDestination(normalizeNotificationDestination(event?.notification?.additionalData));
      });
      await sdk.User.addTag('tiflo_client', 'android_app');
      started = true;
      return true;
    } catch {
      failed = true;
      return false;
    }
  }

  const adapter = {
    status: async () => {
      try { return await state(); } catch { return 'unavailable'; }
    },
    request: async () => {
      if (!started || failed) return 'unavailable';
      try {
        await sdk.Notifications.requestPermission(false);
        return await state();
      } catch {
        return 'unavailable';
      }
    },
    openSettings: async () => {
      if (!started || failed) return false;
      try {
        await sdk.Notifications.requestPermission(true);
        return true;
      } catch {
        return false;
      }
    }
  };

  return { start, adapter };
}
```

If the installed 1.1.6 type/runtime signature for `initialize` differs during execution, stop and verify the installed package before changing this contract; do not guess.

- [ ] **Step 4: Implement coordinator**

`mobile/src/core/notification-coordinator.mjs`:

```js
export function createNotificationCoordinator({ route }) {
  let ready = false;
  let pending = null;

  async function receive(destination) {
    if (!ready) {
      pending = destination;
      return false;
    }
    await route(destination);
    return true;
  }

  async function markReady() {
    if (ready) return false;
    ready = true;
    const destination = pending;
    pending = null;
    if (destination) await route(destination);
    return true;
  }

  return { receive, markReady };
}
```

export function createNotificationRouter(actions) {
  return async function route(destination) {
    const type = destination?.type || 'general';
    const action = actions?.[type];
    if (type === 'general' || typeof action !== 'function') {
      await actions.home();
      return 'home';
    }
    await action(destination);
    return type;
  };
